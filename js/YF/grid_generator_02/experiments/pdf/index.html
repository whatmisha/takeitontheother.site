PDF / проверка редактирования

Отдельный прототип экспорта Pizza Boxer 02. Кириллица, TT Commons Regular и Medium, Lunnen Display 400, абзацы и повороты. Создание файла полностью в браузере.

Проверяем два PDF с одинаковой версткой: с тегами абзацев и без них. Проверка в Illustrator 30.8.1 не пройдена: пользователь получил текст в кривых, вложенные clipping groups и отсутствие стилей. Способ открытия уточняется.

Вернуться в редактор

Готов к проверке. Рабочий макет редактора не используется.

    1. Для сравнения открыть PDF через File → Open в Illustrator 30.8.1, выбрать Previewed Page (первую страницу), выключить Import PDF pages as links for optimal performance.
    2. В блоке 01 изменить ширину текстовой рамки: строки должны переверстаться, сохранив пустой абзац и ручной перенос. Обычное растягивание текста не считается.
    3. В Paragraph Styles и Character Styles проверить наличие именованных стилей Brand / Body, Brand / Medium. Применить стиль к новому тексту.
    4. Проверить Ёё, Йй, NBSP в «250 г», Lunnen и его альтернативы; на второй странице - повороты и размеры. Шрифты для редактирования должны быть установлены в Illustrator.
    5. Посмотреть Layers: нет ли отдельных объектов на каждую строку и ненужных Clipping Groups. Повторить для второго файла.
