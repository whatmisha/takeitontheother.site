**Ревью UI grid_generator_02 — 24 сентября 2026**

Зеленый акцент был добавлен при разработке новой версии. Он не происходил из фреймворка и не был частью согласованной палитры. Исправлена вся новая группа интерфейса: Sides, 2D/3D, навигация и ползунки 3D, кнопки на развертке и выделение граней.

Для сравнения использованы два источника: общий `infra/framework` и исходный `grid_generator`. Список Objects — локальный компонент исходного генератора, а не отдельный компонент общей библиотеки. Поэтому Sides теперь непосредственно использует его классы и иконки. Общая библиотека и оригинальный генератор не изменялись.

**Что обнаружено и исправлено**

- Самостоятельная зеленая палитра `#c4f36c`, ее оттенки и зеленые состояния выбора. Заменены нейтральными токенами; контур грани в 2D использует существующий расчет контрастного черного/белого цвета. Выделение в WebGL получает цвет из `--ui-foreground`.
- Отдельный дизайн строк Sides: другая высота, отступы, пиктограмма-параллелограмм и собственный вариант иконки глаза. Строки переведены на `elements-list`, `element-item-wrapper`, `element-item`, `element-actions`, `element-action-btn`; состояния `active`/`hidden` наследуются от Objects. Пиктограмма убрана. Иконки видимости вынесены в один источник для обоих списков.
- Кнопка Add side с пунктирной рамкой и отдельное оформление списка вариантов. Теперь это существующие `btn-add-object`, `dropdown-menu` и `dropdown-item`; доступность добавлений и Undo сохранены.
- Переключатель 2D/3D был набором специально оформленных кнопок. Теперь используется общий `segmented-control` с настоящей радиогруппой, поддерживающей клавиатуру.
- Ползунки 3D имели нативный зеленый трек. Теперь это `control-group input[type="range"]`: общий тонкий трек и круглый бегунок.
- Селектор конструкции и поле глубины клапана имели собственный набор стилей. Теперь используются `control-group`, `style-select`, `value-display`.
- Locate, Edit grid, Edit in 2D и кнопки камеры оформлялись отдельно. Теперь они используют существующий компактный вариант `text-preset-chip`; декоративные стрелки в новых текстовых кнопках убраны.
- 3D-окно имело отдельные серо-синие оттенки, градиент и радиус 16 px; подписи SVG-кнопок использовали Arial. Теперь окно использует `--color-bg-panel`, `--radius`, общий набор отступов и `--ui-font-stack`. Сетка, верстка и цвет самой упаковки не менялись.

Панель Sides как таковая, Visible, Own Grid, ориентация 0/90/180/270°, независимая сетка и ее поля уже были в исходном генераторе. Они не являются новыми UI-компонентами этого этапа. Base и Flap в селекторах объектов — новые пункты уже существующих селекторов.

Изменения компоновки также не являются новыми контролами: Sides перемещена над Grid и открывается по умолчанию; Grid первоначально свернута; для коротких окон добавлена прокрутка. Адаптация 3D для узких окон остается локальной: при ширине до 900 px боковые панели скрываются в этом режиме. Готового шаблона объемного редактора во фреймворке нет.

**Границы и дальнейшая унификация**

Оригинальные стили списка Objects остаются источником оформления обоих списков. Перенос универсального списка в общий фреймворк можно делать отдельно, с проверкой остальных инструментов. Для текущей задачи расширять общую библиотеку не потребовалось.

Отдельно обнаружено унаследованное поведение плавающих панелей: на окне высотой 720 px открытая Objects может перекрывать нижнюю часть Sides; после сворачивания Objects ее заголовок остается на высоте раскрытой панели. Это связано с прежним размещением независимых панелей и `PanelUiController`, а не с новой палитрой. В этой правке расположение независимой панели Objects не изменялось; общий вертикальный контейнер панелей потребует отдельного решения компоновки.

**Последующая правка компоновки и выбора (24 сентября 2026)**

Dimensions + Grid перенесены в общий контейнер слева вверху и свернуты по
умолчанию. Sides + Objects объединены справа вверху: Sides раскрыта, Objects
свернута. Проблема перекрытия независимой Objects, отмеченная выше, устранена.
Сворачивание больше не фиксирует дочернюю панель на абсолютной высоте.
Обе пары перемещаются за любой из своих заголовков. Раскрытие Grid через
Edit grid синхронизирует стрелку и ARIA и сохраняет Sides открытой.

Автовыбор крышки, обводка по наведению и автовыбор добавленной грани удалены.
Клик по пустому 2D/3D-холсту очищает общий выбор; настройки и перетаскивание
холста его сохраняют. Новых визуальных компонентов для этой правки не добавлено.
Проверки после правки: 194 модульных теста, 157 браузерных проверок.
