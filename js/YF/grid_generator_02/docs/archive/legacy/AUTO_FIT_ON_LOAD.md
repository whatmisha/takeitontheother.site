# Автоматический Fit to Screen при загрузке

## Изменение

При загрузке приложения макет автоматически подгоняется под размер окна с комфортными полями, как было до добавления зума.

## Проблема

После добавления функциональности зума макет загружался в масштабе 100%, что приводило к тому, что он не помещался в окно целиком. Пользователь должен был вручную нажимать "Fit to Screen".

## Решение

Добавлен автоматический вызов `fitToScreen()` после первоначальной отрисовки макета.

### Код

```javascript
// Автоматический fit to screen при загрузке (с задержкой для отрисовки SVG)
requestAnimationFrame(() => {
    setTimeout(() => {
        if (this.zoomPanManager) {
            this.zoomPanManager.fitToScreen();
        }
    }, 100);
});
```

### Почему двойная задержка?

1. **`requestAnimationFrame()`** - ждем следующий кадр рендеринга браузера
2. **`setTimeout(100)`** - даем дополнительное время для завершения отрисовки SVG с помощью getBBox()

Это гарантирует, что SVG полностью отрисован и ZoomPanManager может правильно рассчитать размеры для fit to screen.

## Поведение

### При загрузке страницы:
✅ Макет автоматически подгоняется под размер окна
✅ Сохраняются комфортные поля (~5% по краям)
✅ Весь макет виден целиком

### После ручного зума:
✅ Пользователь может свободно зумировать и панорамировать
✅ При изменении размера окна зум НЕ сбрасывается (сохраняется выбор пользователя)
✅ Кнопка "Fit" всегда доступна для ручного сброса

### При загрузке пресета:
✅ Применяется автоматический fit to screen
✅ Новый макет виден целиком

## UX преимущества

- **Интуитивно** - макет сразу виден целиком
- **Комфортно** - есть поля по краям для визуального дыхания
- **Контроль** - пользователь может изменить зум в любой момент
- **Предсказуемо** - поведение одинаковое при каждой загрузке

## Технические детали

**Файл:** `script.js`

**Место:** Конец конструктора `GridGenerator` (после `this.updateGrid()`)

**Задержка:** 100ms после requestAnimationFrame

**Условие:** Проверка существования `this.zoomPanManager` перед вызовом

## Альтернативы (не реализованы)

❌ **Auto-fit при resize** - может раздражать пользователя, который настроил свой зум
❌ **Auto-fit при изменении параметров** - слишком навязчиво
❌ **Запоминание последнего зума** - усложняет первое впечатление

## Совместимость

✅ Не влияет на существующую функциональность
✅ Работает со всеми методами зума
✅ Совместимо с загрузкой пресетов
✅ Не конфликтует с ручным управлением зумом

## Результат

Теперь приложение ведет себя как раньше - макет сразу виден целиком при загрузке, но с добавлением всех преимуществ векторного зума и панорамирования.
