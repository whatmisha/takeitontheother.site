## ⚠️ Важно помнить

### Принципы безопасного рефакторинга:

1. ✅ **Всегда делайте бэкап** перед большими изменениями
2. ✅ **Тестируйте после каждого шага** - не накапливайте изменения
3. ✅ **Один модуль за раз** - не спешите
4. ✅ **Сохраняйте совместимость** - старый код должен работать
5. ✅ **Используйте обертки** - не меняйте всё сразу

### Если что-то сломалось:

```bash
# Откатиться к последнему бэкапу
cp _backup/iteration_02_settings/script.js script.js
```
