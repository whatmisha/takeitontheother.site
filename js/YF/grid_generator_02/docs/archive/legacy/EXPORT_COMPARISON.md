# Сравнение форматов экспорта

## Старый формат vs Новый формат

### 📊 Структура

| Аспект | Старый формат | Новый формат | Улучшение |
|--------|---------------|--------------|-----------|
| **Организация** | Плоская структура | Логическая иерархия | ✅ Легче ориентироваться |
| **Название пресета** | ❌ Отсутствует | ✅ Автоматическое | ✅ Понятно, что за файл |
| **Расположение текстов** | В середине | В начале | ✅ Быстрый доступ для копирайтера |
| **SVG-код** | Везде | В конце | ✅ Не пугает копирайтера |
| **Читаемость** | Низкая | Высокая | ✅ Понятная структура |
| **Группировка** | Нет | По смыслу | ✅ Логические блоки |

### Новый формат (организованный)

```json
{
  "presetName": "Packaging 382×387mm, Module 3.31mm — 14.11.2025",
  "version": "1.0",
  "timestamp": "2025-11-14T12:34:56.789Z",
  
  "dimensions": {
    "width": 382,
    "height": 387,
    "thickness": 39,
    "unit": "mm"
  },
  
  "texts": [
    {
      "id": "text_1",
      "content": "Премиальная упаковка для пиццы",
      "style": "headline",
      "position": {
        "column": 1,
        "row": 2,
        "baseline": 5
      },
      "width": 6
    }
  ],
  
  "grid": {
    "module": 3.3076,
    "margins": 2,
    "marginsUnit": "mod",
    "columns": 12,
    "rows": 19,
    "rowHeight": 5,
    "linkMode": "module",
    "visibility": {
      "columns": true,
      "rows": true,
      "baseline": true
    }
  },
  
  "colors": {
    "background": "#dadde6"
  },
  
  "typography": {
    "headline": {
      "size": 1.5,
      "lineHeight": 2.0,
      "tracking": -0.015,
      "useXHeight": true,
      "fontWeight": "500"
    },
    "text": {
      "size": 1.0,
      "lineHeight": 2.0,
      "tracking": 0.0,
      "useXHeight": false,
      "fontWeight": "500"
    }
  },
  
  "display": {
    "dimensions": false,
    "labels": false,
    "sidePanels": true,
    "objects": true
  },
  
  "graphics": {
    "blocks": [
      {
        "id": "graphic_1",
        "position": {
          "column": 1,
          "row": 1,
          "baseline": 1
        },
        "height": 3,
        "svg": "<svg>...</svg>"
      }
    ],
    "icons": null,
    "claim": null
  }
}
```

**Преимущества:**
- ✅ **Название пресета** — сразу понятно, что это за макет
- ✅ **Логическая структура** — все разбито по смыслу:
  - 📏 Размеры → dimensions
  - 📝 Тексты → texts
  - 📐 Сетка → grid
  - 🎨 Цвета → colors
  - 📖 Типографика → typography
  - 👁️ Отображение → display
  - 🖼️ Графика → graphics (в конце!)
- ✅ **Тексты в начале** — копирайтеру не нужно прокручивать файл
- ✅ **SVG в конце** — не отвлекает от основного контента
- ✅ **ID для текстов** — text_1, text_2 (легко ссылаться)
- ✅ **Понятные названия** — content вместо text, position вместо columnIndex

## 📈 Улучшения для разных пользователей

### Для копирайтера

| Задача | Старый формат | Новый формат |
|--------|---------------|--------------|
| Найти тексты | 😰 Искать в середине | ✅ В начале, секция `texts` |
| Понять, что редактировать | 😕 `text`: "..." | ✅ `content`: "..." (понятнее) |
| Не сломать файл | 😨 SVG везде | ✅ SVG в конце, можно игнорировать |
| Определить блок текста | 😕 Нет ID | ✅ `text_1`, `text_2` |

### Для дизайнера

| Задача | Старый формат | Новый формат |
|--------|---------------|--------------|
| Найти размеры макета | 😕 В общей куче | ✅ Секция `dimensions` |
| Изменить цвета | 😕 В settings | ✅ Секция `colors` |
| Настроить типографику | 😰 Все вперемешку | ✅ Секция `typography` |
| Понять параметры сетки | 😕 Разбросаны | ✅ Секция `grid` |

### Для разработчика

| Задача | Старый формат | Новый формат |
|--------|---------------|--------------|
| Добавить новый параметр | ✅ Работает | ✅ Автоматически попадает в экспорт |
| Обратная совместимость | ❌ Нет | ✅ Поддерживает старый формат |
| Расширяемость | 😐 Средняя | ✅ Легко добавлять секции |
| Читать код | 😕 Сложно | ✅ Понятная структура |

## 🔄 Обратная совместимость

Новая система поддерживает **оба формата**:

```javascript
// При импорте старого файла
if (data.settings && !data.dimensions) {
  // Это старый формат → конвертируем в новый
  convertOldToNew(data);
}

// При импорте нового файла
if (data.dimensions && data.grid) {
  // Это новый формат → используем напрямую
  useNewFormat(data);
}
```

**Результат:** Можно импортировать файлы, созданные в любой версии!
