# Pizza Boxer 02

Изолированный новый инструмент, скопированный из `grid_generator` 24 сентября 2026.
Все изменения продукта ведутся здесь. Общий фреймворк подключается из соседнего
`infra/framework`; оригинальный генератор и фреймворк не изменены.

## Запуск

Из родительской папки `js/YF`:

```sh
python3 grid_generator_02/tools/serve.py
```

Открыть <http://127.0.0.1:8766/grid_generator_02/>.
Сервер только раздает статические файлы; макет и 3D обрабатываются в браузере.

После изменения исходников, из `grid_generator_02`:

```sh
npm --prefix tools ci
npm --prefix tools run release
npm --prefix tools test
```

`release` собирает хешированные ресурсы и обновляет локальный `index.html`.
После сборки нужно перезагрузить страницу. Установка зависимостей нужна только
при первом запуске или изменении package-lock. Browser smoke:
<http://127.0.0.1:8766/grid_generator_02/tests/browser-smoke.html>.
Smoke использует отдельную IndexedDB `upgrade-pizza-boxer-02-browser-smoke-v1`;
рабочие черновики инструмента он не изменяет. Сервер отправляет Cache-Control: no-store.

## Что уже работает

- Существующий дефолтный пресет сразу открывается в 2D.
- 3D Preview собирает пятигранную крышку без дна из текущего макета.
- Камера: вращение, приближение, панорамирование, виды по граням и изнутри.
- Fold / Unfold и ползунок позволяют проследить складывание каждой боковины.
- Можно выбрать грань кликом на модели или кнопкой вида и перейти к ней в 2D.
- Размеры, видимость сторон, графика, текст и цвет обновляют превью.
- Печатное оформление снаружи; внутри — нейтральная непечатная поверхность.
- Локальная текстура ограничена 2048 px; шрифты встраиваются в промежуточный SVG.
- 3D загружается по запросу и рисуется при изменениях, без постоянного цикла кадров.
- Свой ID приложения, Symbol экземпляра и IndexedDB `upgrade-pizza-boxer-02-v1`.
  Миграция черновиков из прежних генераторов отключена.

Добавлен переключатель Construction:

- Lid — исходная пятигранная крышка.
- Box with base — шесть граней: крышка, дно и четыре стенки.
- Box with flap — семь граней: та же коробка с закрывающим клапаном.

У конструкций с дном три стенки соединены с дном, задняя стенка соединяет дно
и крышку. Отдельный ползунок Open lid открывает крышку, сохраняя положение
корпуса. Глубина клапана настраивается и ограничивается глубиной коробки.
Base и Flap доступны для текста, графики и собственной сетки; переход из 3D
открывает соответствующую грань в 2D. При смене конструкции верстка неиспользуемых
граней сохраняется. Конструкция входит в undo/redo и автосохранение.

Новые JSON экспортируются в формате 2.0: поле construction хранит тип и параметр
клапана, dimensions.depth явно обозначает глубину коробки. Пресеты 1.2 читаются
как пятигранные крышки. Размеры артборда SVG/PDF охватывают всю новую развертку.
Пути сгибов представлены иерархией панелей в PackagingModel и используются
для 2D, hit testing, экспортной геометрии и UV текстур 3D.

Панель Sides теперь открыта по умолчанию и содержит все грани, включая крышку.
У каждой грани видны название, физические размеры в мм и переключатель видимости.
Выбор синхронизирован между панелью, кликом по развертке и 3D. Locate приближает
выбранную грань в 2D или поворачивает к ней камеру в 3D. Слева вверху связаны
Dimensions и Grid — обе свернуты по умолчанию. Справа вверху связаны Sides
(раскрыта) и Objects (свернута). Каждая пара перемещается за любой заголовок;
сворачивание панелей независимо, длинное содержимое прокручивается внутри.
Главная сетка находится в Grid слева; собственная сетка и ориентация — в Sides.

Кнопка Add side предлагает доступное дополнение конструкции: сначала Base,
затем Flap. Те же действия доступны кнопками + у края развертки. Скрытые грани
можно восстановить через панель или кнопку на их месте в развертке. Добавление
дна также восстанавливает соединяющую заднюю стенку, если она была скрыта.
Верстка и собственные сетки сохраняются; каждое добавление — одно действие Undo.
Это добавление частей текущих конструкций 5/6/7, а не свободное моделирование
произвольной топологии. Импорт сложных дайкатов остается отдельным этапом.

Новые текст и графика создаются на выбранной стороне. Если она скрыта, добавление
объекта восстанавливает ее в той же операции Undo. Без выбранной стороны новый
объект попадает на главную грань. При запуске ничего не выделено; наведение и
добавление грани не включают обводку. Явный выбор в списке, на развертке или в 3D
включает выделение. Клик по пустому холсту в 2D/3D снимает его во всех видах;
перетаскивание холста и работа с настройками сохраняют выбор. Выбор, Locate
и камера не изменяют документ. Контуры выделения и кнопки не попадают в экспорт
или текстуру. Fit теперь действительно уменьшает развертку между панелями,
учитывает поворот холста; кнопки добавления сохраняют размер при масштабировании.

Геометрия пока состоит из тонких плоскостей: компенсации толщины картона,
производственные клеевые клапаны и тубусы относятся к следующим этапам.
Поле Depth — глубина крышки, а не толщина материала. PDF-экспорт унаследован
из текущего генератора; требования к редактируемым абзацам Illustrator еще
не реализованы. Импорт дайкатов намеренно не добавлен.
