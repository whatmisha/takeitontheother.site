# YF Projects

Коллекция интерактивных проектов и генераторов паттернов.

## Структура проектов

Проекты организованы в три основные категории:
- **Bodycore** - генераторы паттернов для Bodycore
- **Lunnen** - генераторы паттернов, эффекты и демо
- **Muted** - интерактивные проекты для Muted

## Автоматическое обновление списка проектов

Список проектов в `index.html` генерируется автоматически с помощью Python скрипта.

### Использование

Когда вы добавляете новый проект в папки `bodycore/`, `lunnen/` или `muted/`, запустите скрипт для обновления списка:

```bash
python3 generate-projects-list.py
```

### Как работает

Скрипт сканирует папки `bodycore/`, `lunnen/` и `muted/` и автоматически находит все проекты, которые содержат `index.html`:
- В корне папки проекта (например, `lunnen/dither/index.html`)
- В подпапке `/01/` (например, `lunnen/rays_pattern_generator/01/index.html`)

**Важно:** Скрипт не добавляет в список:
- Папки, в которых нет `index.html` ни в корне, ни в `/01/`
- Вложенные подпапки второго уровня (например, `dither/02/` или `hyperspace/03/`)

### Добавление нового проекта

1. Создайте папку с проектом в `bodycore/`, `lunnen/` или `muted/`
2. Убедитесь, что в папке есть `index.html` (в корне или в подпапке `/01/`)
3. Запустите `python3 generate-projects-list.py`
4. Список в `index.html` обновится автоматически

### Формат названий

Скрипт автоматически форматирует названия папок:
- `pattern_generator` → Pattern Generator
- `chladni-sound-pattern` → Chladni Sound Pattern
- `asterisk_pattern_generator` → Asterisk Pattern Generator
