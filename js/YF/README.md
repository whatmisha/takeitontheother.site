# YF Projects

Коллекция интерактивных проектов и генераторов паттернов.

## Структура проектов

Проекты организованы в три основные категории:
- **Bodycore** - генераторы паттернов для Bodycore
- **Lunnen** - генераторы паттернов, эффекты и демо
- **Muted** - интерактивные проекты для Muted

## Два варианта использования

### Вариант 1: Динамическая генерация (index.php) ⭐ Рекомендуется

Файл `index.php` автоматически сканирует папки и генерирует список проектов при каждой загрузке страницы.

**Преимущества:**
- Список обновляется автоматически при добавлении/удалении проектов
- Не требуется запускать скрипты вручную

**Требования:**
- Сервер с поддержкой PHP

**Использование:**
Просто откройте `index.php` в браузере. Список всегда актуален.

### Вариант 2: Статическая генерация (index.html)

Список проектов в `index.html` генерируется с помощью Python скрипта.

**Преимущества:**
- Работает на любом хостинге (не требует PHP)
- Быстрая загрузка страницы

**Требования:**
- Python 3 для запуска скрипта генерации

**Использование:**

Когда вы добавляете новый проект в папки `bodycore/`, `lunnen/` или `muted/`, запустите скрипт для обновления списка:

```bash
python3 generate-projects-list.py
```

---

## Как работает автоматическое сканирование

Оба варианта (PHP и Python) используют одинаковую логику:

Сканируются папки `bodycore/`, `lunnen/` и `muted/` и автоматически находятся все проекты, которые содержат `index.html`:
- В корне папки проекта (например, `lunnen/dither/index.html`)
- В подпапке `/01/` (например, `lunnen/rays_pattern_generator/01/index.html`)

**Важно:** Скрипты не добавляют в список:
- Папки, в которых нет `index.html` ни в корне, ни в `/01/`
- Вложенные подпапки второго уровня (например, `dither/02/` или `hyperspace/03/`)

## Добавление нового проекта

1. Создайте папку с проектом в `bodycore/`, `lunnen/` или `muted/`
2. Убедитесь, что в папке есть `index.html` (в корне или в подпапке `/01/`)
3. **Если используете index.php** - всё готово! Просто обновите страницу
4. **Если используете index.html** - запустите `python3 generate-projects-list.py`

### Формат названий

Скрипт автоматически форматирует названия папок:
- `pattern_generator` → Pattern Generator
- `chladni-sound-pattern` → Chladni Sound Pattern
- `asterisk_pattern_generator` → Asterisk Pattern Generator
