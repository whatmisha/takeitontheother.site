# Чистые адреса и единая папка инфраструктуры

2026-09-22. Решение пользователя заменяет предыдущую схему `tools/`.

## Структура

```text
upgrade/
  index.html
  package.json
  .gitignore
  sparky/                    и ещё 15 папок инструментов
  infra/
    framework/               общий runtime, стили, шрифты и vendor
    catalog/                 политика каталога и тесты структуры
    scripts/                 сборочные/проверочные сценарии
    qa/                      стенды, fixtures и доказательства
    docs/                    планы и отчёты
    baselines/               исторические исходные снимки
    releases/                исторические отчёты выпусков
    extracted/               отдельный UI Garage, не runtime приложений
    TOOL_CATALOG.json        актуальные адреса/статусы
    APPLICATION_CAPABILITIES.json
    …                        остальные служебные JSON-манифесты
```

Папка `tools/` удалена после перемещения содержимого; копий, симлинков-алиасов, редиректов и `<base>` нет. Метаданные Finder сохранены, но игнорируются Git. Частные ресурсы и тесты приложений остаются внутри соответствующих инструментов.

Адреса снова `upgrade/sparky/`, `upgrade/grid_generator/` и т. д. Промежуточные адреса `upgrade/tools/<id>/` больше не обслуживаются. Исходные `YF/lunnen/` и `YF/muted/` не изменены. Это решение касается только `upgrade`, не подменяет оригинальные инструменты сайта.

Название `infra` без подчёркивания выбрано для совместимости со статической публикацией: Jekyll по умолчанию исключает имена, начинающиеся с `_`. Это организационная папка, не закрытая область: её runtime-ресурсы должны оставаться доступны браузеру. Настройки хостинга вне upgrade не менялись.

## Сохранность и кеш

- Перед переносом сняты хеши 1346 файлов рабочего дерева, включая незакоммиченные правки. Сразу после перемещения все файлы сверены; запись — `infra/qa/ROOT_LAYOUT_RELOCATION.json`.
- Исходные baseline/acceptance JSON и замороженные fixtures не переписаны. Старые адреса в отчётах преобразуются только на границе чтения через `infra/scripts/lib/upgrade-paths.mjs`.
- Каталог, QA-ссылки, npm-команды, импорты, CSS и сборочные пути обновлены. Pizza Boxer пересобран из исходников; framework остаётся внешним общим модулем, не встраивается в bundle.
- На восстановленном URL браузер действительно использовал старый кеш Sparky. Версия `layout=root-infra-1` добавлена к затронутым зависимостям и их входным цепочкам. После обновления Sparky отрисовывает персонажа и читает framework из `infra/`.
- Единственная правка стороннего p5 — новый относительный адрес уже локализованных переводов; обратная подстановка проверяется по официальному upstream SHA-256.

Одноразовые `consolidate-infrastructure.mjs`, `version-relocated-assets.mjs` и старый `relocate-tools.mjs` не запускать повторно для продолжения интеграции. Обычный рабочий цикл — команды npm ниже.

## Проверка

Команды выполняются из `upgrade/`:

```sh
npm run check:migration-foundation
npm run check:isolation
npm run check:ui-contract
npm run test:tier1
npm run test:tier2
npm run migration:sources:check
```

Финальный прогон 2026-09-22: все шесть команд выше завершились с кодом 0; 625 node:test-проверок плюс предметные проверки Wordplayer/Keyboarder. Boundary: 502 runtime text files, 20 entrypoints, 7 внутренних symlink зависимостей. Пакетные 33 проверки новых копий также прошли с Node permission mode, разрешающим чтение только внутри upgrade. `git diff --check` пройден.

Тест структуры запрещает лишние папки/файлы в корне, проверяет прямую навигацию всех 16 инструментов и побайтную неизменность исторических свидетельств. Изоляция проверяет все runtime-входы и внутренние зависимости.

Браузерная проверка этого переноса — запуск всех 16 страниц по чистым URL, интерфейс/загрузка ресурсов, работа ссылок QA. После исправления кеша дополнительно проверены цепочки модулей исходных инструментов. UI-аудитор Wander Bender: 0 групп с отклонениями, 12 совпадают, 4 требуют ручной проверки (iframe 1440×900). Из предупреждений повторилось ожидаемое EAN-13 checksum mismatch исходных данных Sticky Fingers; данные не подменялись. Этот проход не заменяет полную приёмку экспортов, микрофона, всех режимов и мобильных сценариев.

Известные ограничения, не скрытые переносом:

- Исторический `check:keyboard` ожидает у Pulsar три сворачиваемые панели, текущий интерфейс содержит две. Это прежнее расхождение inventory, не результат перемещения; manifest не подгонялся.
- `manifest:check` требует оригинальный донор `js/othersite-ui-framework/v3`, которого сейчас нет по прежнему пути. Локальная проверка 50 immutable framework-файлов проходит без донора; новые восемь источников проверяются отдельной `migration:sources:check`.
- Восемь новых инструментов остаются `migrating`: перенос папок не означает завершение унификации UI или принятие их исходных дефектов.
