# Gate G10 — semantic controls and variance audit

Дата: 2026-09-05. Статус: **Passed**.

G10 исправляет regression составной группы Wordplayer, унифицирует grid pills
Pizza Boxer и Sticky Fingers, возвращает intrinsic wrapping Keyboarder и
фиксирует остаточные UI variance решения без расширения framework частной
логикой.

```sh
npm run gate:g10:static
```

Gate включает полный G9 regression и машинно проверяет custom-spacing escape,
intrinsic Layers pills, общий `#d2d2d2` pill state, отсутствие icons/borders в
grid pills и завершённый semantic variance audit.
