# INT-08 — Chladni: реальный микрофон и завершение миграции

2026-09-23, локальный Codex in-app browser, `http://localhost:8010/upgrade/chladni-sound-pattern/`. Пользователь подтвердил системный доступ после INT-07. Краткий локальный захват уже был явно разрешён. Аудиозапись и отправка звука не выполнялись; используются только локальные p5 AudioIn/FFT и графический экспорт.

## Результат

Аппаратный блокер INT-07 снят. Chladni принят в согласованном desktop-объёме: **все 16 инструментов accepted**, все ссылки доступны в главном каталоге. Реальный звук дополнен прежними детерминированными тестами отказа, позднего разрешения и числовой математики. Статус не означает сертификацию всех браузеров, аудиоустройств или мобильных платформ.

Предметный renderer и framework в этом проходе не менялись. Обновлены доказательства, контракт, каталог, генерируемые индекс/список аудитора и независимое ожидание accepted в тесте. Frozen baseline и оригиналы сохранены.

Клики по скрытым checkbox в пользовательской вкладке дали неоднозначный результат автоматизации. Поэтому зачтена только чистая матрица в отдельной вкладке: фокус на конкретном input и Space, затем чтение checked/disabled/value из DOM. Ошибка координат не объявлена дефектом генератора.

## Что именно покрыто тестами, а не аппаратным наблюдением

- `capture-status.test.mjs`, `integration.test.mjs`: отказ и retry, дедупликация Start, Stop до unlock, Stop при pending permission, закрытие поздно выданного stream. Системное разрешение специально не отзывалось.
- `artifact-parity.test.mjs`: нулевой и ненулевой FFT-сигнал, четыре сочетания reactive осей, smoothing/amplitude/threshold против неизменённого исходного baseline; pause/stop не читают новый кадр. Абсолютная тишина не создавалась физически.
- Тот же suite: PNG получает последний реально отрисованный state/threshold и ожидает encoding до удаления временной поверхности.
- Cleanup: настоящий Stop/restart/уход проверены через UI; `CaptureSession.stop()` вызывает закреплённый p5 `AudioIn.stop()`, который останавливает все stream tracks и отключает mediaStream. Нативный системный индикатор захвата недоступен автоматизации и **не объявляется визуально проверенным**.
- BFCache suspend/resume покрыт общими lifecycle-тестами; наблюдённый live Back был полной повторной загрузкой. Микрофон не запускается автоматически в обоих путях по коду.

Состояние кадра сохраняется, но 1200px PNG — повторный рендер из него, не увеличение 600px preview. Совпадение двух экспортов не доказывает pixel-parity preview/export при разном разрешении.

## Проверки и границы

Полностью повторены `test:tier1`, `test:tier2`, `check:migration-foundation`: **686 Node tests passed, 0 failed**. Прошли `check:isolation`, `migration:sources:check`, `check:ui-contract`, `check:keyboard`, `git diff --check`. Boundary check: 513 runtime text files, 20 entrypoints, семь внутренних symlink; 32 исходных файла / 791667 bytes неизменны. После `catalog:sync` браузер показал 16 ссылок; переход по новой Chladni-ссылке открывает stopped. Главная первоначально показывала кешированные 15 ссылок, обычный reload обновил её.

Итоговый прогон и ограничения также записаны в `INTEGRATION_8_PROGRESS.md`. Новые аппаратные проверки не считаются дополнительными Node tests. Все намеренные изменения репозитория ограничены `upgrade/`; известный изменённый `.DS_Store` снаружи не тронут. Файлы Downloads только прочитаны, не удалены. Commit/push не запускались.

Сохранённые legacy export/resize/tone особенности остальных инструментов описаны в INT-06. Их изменение — отдельное улучшение, не незавершённый перенос. Следующий шаг после этой приёмки — review и, по отдельному запросу пользователя, commit/push текущей работы.
