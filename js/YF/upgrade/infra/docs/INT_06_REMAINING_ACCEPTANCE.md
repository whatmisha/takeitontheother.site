## Calendar: исправлены предметные ошибки, сохранена политика экспорта

- SVG-операции выделены в частный `calendar-randomizer/scene.js`, не в общий UI framework.
- Randomize, Reset и export работают с одинаковым набором графических узлов первых трёх уровней. `defs`, маски, clip paths, gradients, symbol resources и metadata не получают случайных трансформаций.
- Исходная матрица узла фиксируется до первой анимации, включая transform-атрибут и CSS transform. Перемещение её дополняет; Reset возвращает исходную геометрию, а не перекрывает её нулевой трансформацией.
- Экспорт больше не удаляет весь `style`: сохраняются fill, stroke, opacity, filter и ссылки на ресурсы. `none`, `url(...)`, `currentColor`, наследование и переменные не заменяются цветом. Alpha в hex/RGBA/HSLA сохраняется.
- **Экспорт по-прежнему создаёт новую случайную композицию.** Во время перехода он использует исходные матрицы и новые смещения, не промежуточный кадр; живой SVG не изменяется. WYSIWYG текущего кадра не обещается и без решения пользователя не вводился.
- При уходе прерываются XHR и подписки. Поздний ответ не заменяет новое artwork. BFCache rebind использует прежнюю scene, не принимает анимированное состояние за новую базу. Readouts синхронизируются с восстановленными браузером range values.

### Доказательства Calendar

1. `batch7/calendar-fixtures.html` — воспроизводимый локальный browser test. Пять SVG: вложенная синтетическая fixture и четыре настоящих шаблона. Количество анимируемых узлов: 7 / 208 / 74 / 65 / 69. Проверяет реальные CTM до/после Reset, defs, CSS/attribute transforms, paint/opacity/alpha, валидный XML и экспорт во время перехода. Это проверка известных шаблонов и fixture, не обещание поддержки произвольного пользовательского SVG.
2. В настоящем интерфейсе 20 последовательных смен шаблона → один Randomize → ровно одна запись выполнения в журнале. Одна панель и один dock.
3. Четыре SVG скачаны сразу после Randomize, 720×320, конечные значения, стили сохранены. Metadata/SHA-256: `INT_06_EXPORT_EVIDENCE.json`. Дополнительная alpha-правка проверена fixture; исходные четыре шаблона не содержат такого paint-alpha.
4. Node test исполняет настоящий runtime с подставленным DOM/XHR: 20 переключений, одна подписка, отменённый и поздний ответ, возврат, сохранение scene base и readouts.
5. Реальная навигация туда/назад выполнена. Браузер восстановил range в собственное значение (53 вместо предшествовавших 31); readout теперь показывает те же 53. Это не доказательство побайтного восстановления всей формы на каждом BFCache/reload. Сценарий не обещает project persistence.

## Единственный обязательный остаток

После явного разрешения пользователя — реальный микрофон Chladni на localhost: grant/deny/retry, звук/тишина, независимые reactive X/Y, pause/resume, экспорт, Stop и уход со страницы. Проверить выключение индикатора capture и отсутствие автостарта при возврате. Затем evidence → `accepted` → catalog sync → checks. До разрешения не нажимать Start и не выдавать числовые FFT-заглушки за проверку устройства.

Calendar current-frame export, сохранение случайных композиций при resize/tab и новый взаимоисключающий Tone можно обсуждать отдельно: они не нужны для сохранения исходной функциональности миграции. Повторное копирование приложений, перенос инфраструктуры или переписывание общего renderer не требуются.
