# Восемь новых инструментов: реализация и приёмка

Дата: 2026-09-22. Изменения находятся в рабочем дереве `main`, только внутри `upgrade/`. Commit/push не выполнялись. Это отчёт о текущей реализации, **не заявление о закрытии всех четырёх шагов**.

## Состояние четырёх шагов

| Шаг | Результат |
| --- | --- |
| 1. Rays T.3b | Выполнен: Canvas и SVG используют одну проверенную сцену; дублирующая геометрия удалена из adapter. |
| 2. Rays: общий UI и исправления | Реализовано и проверено unit/artifact/browser. Формальная T.7 ещё не закрыта, ссылка в основном каталоге пока не включена. |
| 3. Остальные семь | Все семь подключены к общему UI, не просто скопированы. Исправлены перечисленные ниже дефекты. Предметные renderer/model сохранены за границей host. |
| 4. Общая приёмка | Автотесты, изоляция, браузерные интерфейсы и реальные файлы проверены. Остаток: console gate аудитора, живой микрофон, отдельные пограничные сценарии и решения о поведении. |

Все 16 приложений физически находятся в `upgrade/<tool>/`; инфраструктура — в `upgrade/infra/`. У новых восьми остаётся `state=migrating`, у контрактов `status=ui-integration`, у приёмки `status=partial`. Они доступны через `/upgrade/infra/qa/migrations/`. Не переключать `accepted` только ради появления ссылок.

## Общий механизм

`infra/framework/src/ui/GeneratorHost.js` — opt-in adapter поверх существующих ToolUiController, PanelManager, UnifiedColorPicker и FileIntakeController. Старые восемь приложений его не подключают.

- Настоящие input/select/button перемещаются в общие панели, а не клонируются. Сохраняются их ID, диапазоны, частные обработчики и история.
- Общие шрифты, кнопки, слайдеры, pills, dropdowns, разделители, цвета и отступы берутся из framework. Старые полные CSS новых приложений больше не подключаются; файлы сохранены как материал миграции.
- Экспорт, его клавиатура, справка и feedback принадлежат одному реестру. Generate, Center, Undo/Redo, Randomize, Start/Stop/Pause остаются в панелях.
- Сводки обрезаются в фиксированных 300 × 47 px свёрнутых панелях. `⌘/Ctrl+\` сворачивает/восстанавливает их.
- Settings располагается над Tone, чтобы рост превью изображения не закрывал соседнюю панель. Ручное перетаскивание отключает автоматическое размещение этой пары.
- Загрузка/повторный файл/ошибка/удаление источника используют общий FileIntake. Декодирование и изменение модели остаются частными. Устаревшая операция после ухода со страницы не должна менять новый документ.
- PNG feedback ожидает завершения `toBlob`, после чего освобождается временный graphics buffer.
- Обработчики выключаются на pagehide и восстанавливаются при BFCache-return. Микрофон при возврате сам не включается.
- Общий host не владеет p5 canvas. Сохранены отдельные локальные p5 1.4.0, 1.7.0, 1.9.0 и p5.sound; их исходные hashes проверяются.
- Входные цепочки новых приложений версионированы `integration-3`, host/CSS — `v=3`: в браузере обнаруживался старый кеш под прежними URL.

### Уточнение порядка плана

Для Rays извлечение чистой сцены завершено. Для остальных семи выбран первый безопасный срез: общая UI-оболочка и команды, неизменные частные генераторы и renderer, тесты фактической генерации/экспорта. Переписывание всех p5/Canvas-моделей одновременно не требуется для централизованного UI. Дальнейшее извлечение engine выполняется отдельно, после приёмки, с сохранением fixtures. Общего «генератора всего» нет.

## По инструментам

### Rays Pattern

Canvas и SVG теперь читают `engine/scene.js` через `engine/renderers.js`. Семь golden-сценариев не перезаписаны. Сохранены разрешённые количества лучей, формулы, порядок примитивов, смещение рядов и историческое дублирование вертикального луча у чётных count.

Исправлены восстановление внешнего радиуса перед следующим изменением gap, потеря tone-параметров в image filename/storage, конфликт gradient/image флагов, URL cleanup и владение export shortcut. Общие панели Pattern/Tone/Settings, image intake с Remove, сводки и feedback подключены. Изображение не кодируется в filename: это по-прежнему не полный project round-trip.

### Random Lines

Общие Pattern/Tone/Settings; Generate остаётся явным. `sf` разбирается до `s`, scale больше не превращается в NaN из-за safe field. Добавлены empty/stale/ready состояния, фактическое число размещённых линий и сообщение о лимите; пустой/устаревший результат не экспортируется как готовый. Image intake умеет повторный файл, ошибки с сохранением прежнего источника и Remove. Геометрия, RNG и предел попыток не изменены.

Legacy gradient/image flags в этом приложении пока допускают совместное включение с приоритетом image и gradient fallback при отсутствии файла. Это отдельный остаток унификации выбора режима, не выданный за исправленный дефект.

### Pattern 02

Одна общая панель, SVG dock, Undo/Redo с единой клавиатурой. Исправлена история клавиатурных изменений слайдера; mouseup/touchend/touchcancel вне слайдера завершает транзакцию. Один владелец p5 canvas. SVG проверен по всем восьми комбинациям toggles и двум наборам параметров.

### Asterisk

Общие controls/panel/export. Исправлена лишняя нулевая копия в SVG axes mode: число кривых совпадает с preview при 0/1/2/7 слоях в обоих режимах, всех восьми масштабах 1:1–1:128 и обоих caps (128 комбинаций в автоматическом тесте). Интенциональная модульная сетка по-прежнему входит в экспорт. Синхронный максимум 100 слоёв не запускался в живом браузере и не объявлен безопасным стресс-тестом.

### Pattern 01

Сохранены пять режимов, частные диапазоны, canvas и модели. Общий Mode/Pattern UI, один SVG export. Исправлены отсутствующий keyboard export Diagonal Grid и отсутствующий публичный `rectangleModule.exportSvg`. Магнитные шоткаты ограничены активным режимом и не перехватывают ввод. Выбранный режим имеет `aria-pressed`; аудитор проверяет его как выбранный переключатель, а не обычную кнопку.

Подгонка Diagonal Grid при resize меняет CSS-размеры, не буфер/прикреплённые точки. Для остальных режимов исходная регенерация при переключении/resize сохранена до решения пользователя. Не обещается сохранение случайной композиции между вкладками.

### Hyperspace

Общая панель, реальные HSB-поля, PNG dock, Pause/resume по Space. UI-клики/drag не меняют vanishing point. Экспорт сохраняет состояния частиц и их собственные origins; ожидает PNG encoding перед удалением graphics. Legacy регенерация при resize пока сохранена.

### Calendar Randomizer

Inline runtime извлечён в `script.js`. Шаблоны и обработчики имеют lifecycle: предыдущий XHR и подписки отменяются, поздний ответ не подменяет новый шаблон. Поиск artwork ограничен `#svg-container > svg`; иконки framework не рандомизируются. Четыре template сохранены, общий цветовой UI/команды подключены. 20 переключений не размножают Randomize-обработчик.

**Экспорт пока повторно рандомизирует композицию, как оригинал.** Решение «экспортировать текущее/конечное состояние анимации» не принято вместо пользователя. Дополнительные fixtures вложенных defs/base transforms и цветовых ссылок ещё нужны; текущие четыре SVG сами по себе не доказывают поддержку произвольного SVG.

### Chladni

Общие Pattern/Microphone панели и PNG dock. `CaptureSession` ждёт разрешения, объединяет повторный Start, допускает retry после отказа и выключает поздно предоставленный stream после Stop. Ручной X/Y редактируются независимо; отображаемые числа следуют программным изменениям p5 sliders. PNG использует последний реально отрисованный threshold/state и ждёт encoding.

Числовые FFT-последовательности, permission fake, start/stop/pause, статический рисунок и скачанный PNG проверены. **Реальный микрофон не включался: ожидается разрешение пользователя.** Уход со страницы всегда останавливает capture, включая повторный BFCache-return.

## Проверки и доказательства

### Автоматические

На этом проходе пройдены `test:tier1`, `test:tier2`, `check:migration-foundation`, `check:isolation`, `check:ui-contract`, `check:keyboard`, `gate:g0`, `migration:sources:check`. После последних изменений повторно пройдены расширенный Asterisk suite, весь `check:migration-foundation`, isolation/UI/keyboard/G0/source checks и `git diff --check`. В рабочем дереве 81 изменённый/новый файл; все находятся внутри `js/YF/upgrade/`.

Текущее покрытие: framework 97; Sparky 200; Pizza 172; Wordplayer 7; Keyboarder 6; Sticky 10; Pulsar 20; Dither 19; Wander 12; catalog 17; batch7 62; Rays 38 — **660 Node tests**, без повторного подсчёта одних тестов из разных npm-команд. Плюс отдельные предметные проверки Wordplayer/Keyboarder. `check:ui-contract`/`check:keyboard` исторически охватывают исходные восемь, не все 16.

- Новые `batch7/integration.test.mjs` и `artifact-parity.test.mjs` проверяют фактические private functions/exports с фиксированным RNG, все пять SVG Pattern 01, PNG lifecycle, FFT и известные исправления.
- 29 T.2 файлов заморожены отдельно. Их hashes сравниваются с исходным copy manifest; старые ожидаемые результаты не заменены новым кодом.
- Source baseline новых восьми: 32 файла, 791667 bytes; оригиналы только прочитаны. Проверка границ охватывает 507 runtime text files, 20 entrypoints, семь внутренних dependency symlink без выхода из upgrade.
- G0 теперь проверяет сохранённый манифест локально. Проверка донора вынесена в явную `manifest:check-originals`. Исторический снимок не перезаписан.
- Текущие две панели Pulsar указаны отдельным `CURRENT_UI_INVENTORY.json`; исторический keyboard acceptance не переписан.

### Браузер

Codex in-app browser, локальный сервер 8010. Новые восемь проверены на 1440×900, 1280×800, 1024×768: 24 страницы без горизонтального overflow, один dock, смещение его центра 0 px, панели шириной 300 px помещаются в окно. Проверены DPR 1 в viewport override и DPR 2 в обычном окне.

Восемь исходных приложений открылись без новых ошибок/overflow в smoke-проходе. ### Реальные скачанные файлы

18 файлов из восьми инструментов созданы браузером и прочитаны с диска. Имена, время, размер, SHA-256, SVG dimensions/primitives и PNG decode сведены в `infra/qa/migrations/INTEGRATION_EXPORT_EVIDENCE.json`. В исходных пяти режимах Pattern 01 SVG конечный и векторный; Random Lines — 3000×1000; Pattern 02 — 1280×720; Asterisk — 1920×1080; Calendar — 720×320; Chladni PNG — 1200×1200; Hyperspace PNG — 2560×1440 при DPR 2. PNG IDAT успешно распакован. Файлы не удалялись и не перезаписывались; повторные скачивания получили системные суффиксы.

Это подтверждает создание файлов, но не эквивалентно pixel-parity для всех режимов/анимационных кадров. В репозитории сохранена metadata-проверка, а не копии пользовательской папки Downloads.

## Что ещё нельзя объявить завершённым

1. **Console gate UI-аудитора.** В 17:29:37.747 UTC вновь получен `MutationObserver.observe: parameter 1 is not of type Node`, без filename/stack. Все восемь замеров закончились. Общий `installDocumentObserver` имеет guard/try-catch; в pinned p5 есть собственные observers. Этого недостаточно для атрибуции. Нельзя подавить сообщение, заменить p5 или назвать его ошибкой браузера без доказательств. Нужен воспроизводимый сценарий с источником/stack, затем адресное исправление и повторная серия переходов iframe.
2. **Chladni на реальном устройстве.** После явного разрешения пользователя: grant/deny/retry, звук/тишина, оба независимых reactive axis, pause/resume, PNG того же кадра, Stop и уход со страницы. Убедиться, что capture indicator гаснет и не включается на «Назад».
3. **Решения о сохранении состояния.** Calendar: сохранить legacy re-randomizing export или экспортировать текущее/конечное состояние. Pattern 01/Hyperspace: сохранить legacy regeneration при resize/переключениях или ввести сохранение композиции. До ответа текущие оригинальные правила не менялись.
4. **Закрыть оставшуюся T.7, затем включить ссылки.** Вложенные SVG fixtures Calendar, source error/cancel в Rays живым браузером, late-decode/BFCache и bounded Asterisk scale/caps/grid стресс в браузере. Rays Remove и magnetic add/undo/clear уже проверены; Asterisk scale/caps покрыты автоматическими 128 комбинациями, что не заменяет browser stress. Для Random Lines отдельно решить переключатель mutually-exclusive Tone, не теряя исходный image→gradient fallback. После этого приложить evidence по каждому инструменту, сменить contracts/catalog на accepted и выполнить `npm run catalog:sync`, повторить isolation/регрессию.

Нельзя считать эти пункты выполненными лишь потому, что интерфейсы уже используют framework. Новый объём реализации не требует повторного копирования папок или переноса инфраструктуры.

## Продолжение

Читать этот отчёт первым, затем соответствующий контракт и тесты. Старые отчёты INT/T.2 описывают состояние до этой реализации. Не запускать снова `copy-remaining-tools`, `relocate-tools`, `connect-rays-scene`, `extract-calendar-runtime` или `connect-generator-styles`.

Сначала console gate и разрешение на microphone; независимые fixture/UI проверки можно продолжать без микрофона. Записи только внутри upgrade. Сохранить текущую геометрию и hashes frozen fixtures. После каждого изменения — затронутый suite, затем общая регрессия. Commit/push только по отдельному запросу.
