## Общий механизм

Текущая UI-доработка 2026-09-23: английские интерфейсы всех 16 инструментов, подписи хоткеев только у основного экспорта, вес 400 у тёмных кнопок, удаление двух заголовков Pulsar и кнопок истории Pattern 02 с сохранением undo/redo. Общие версии теперь CSS `uiq-5`, GeneratorHost `v=6`, входы новых инструментов `integration-8`. Пройдено 692 Node tests и браузерный проход всех 16 инструментов. Подробности и границы проверки — [UI policy](UI_POLICY_2026_09_23.md). Эти UI-правки не опубликованы.

После INT-08, 2026-09-23: исправлена стрелка сворачивания GeneratorHost. Вместо шрифтового символа используется тот же SVG 10×6 / `M1 1L6 6L11 1`, что в Sparky и Wordplayer. Исправлены также Canvas demo и шаблон новых инструментов UI Garage. Все восемь новых приложений подключают host `v=5` через входы `integration-7`. Проверены 14 стрелок в браузере, сворачивание Asterisk до 300×47 и раскрытие с клавиатуры; добавлены два framework-теста и один portable-template тест. Прошли framework (101), migration-foundation (141), portable visual (4), portable manifest/verify, isolation и originals check. Накопленное основное покрытие — 688 Node tests; полный tier1/tier2 последний раз выполнялся в INT-08. Эта UI-правка ещё не закоммичена и не опубликована.

`infra/framework/src/ui/GeneratorHost.js` — opt-in adapter поверх существующих ToolUiController, PanelManager, UnifiedColorPicker и FileIntakeController. Старые восемь приложений его не подключают.

- Настоящие input/select/button перемещаются в общие панели, а не клонируются. Сохраняются их ID, диапазоны, частные обработчики и история.
- Общие шрифты, кнопки, слайдеры, pills, dropdowns, разделители, цвета и отступы берутся из framework. Старые полные CSS новых приложений больше не подключаются; файлы сохранены как материал миграции.
- Экспорт, его клавиатура, справка и feedback принадлежат одному реестру. Generate, Center, Undo/Redo, Randomize, Start/Stop/Pause остаются в панелях.
- Сводки обрезаются в фиксированных 300 × 47 px свёрнутых панелях. `⌘/Ctrl+\` сворачивает/восстанавливает их.
- Settings располагается над Tone, чтобы рост превью изображения не закрывал соседнюю панель. Ручное перетаскивание отключает автоматическое размещение этой пары.
- Загрузка/повторный файл/ошибка/удаление источника используют общий FileIntake. Декодирование и изменение модели остаются частными. Устаревшая операция после ухода со страницы не должна менять новый документ.
- PNG feedback ожидает завершения `toBlob`, после чего освобождается временный graphics buffer.
- Обработчики выключаются на pagehide и восстанавливаются при BFCache-return. Микрофон при возврате сам не включается.
- Общий host не владеет p5 canvas. Сохранены отдельные локальные p5 1.4.0, 1.7.0, 1.9.0 и p5.sound; их исходные hashes проверяются.
- Входные цепочки новых приложений версионированы `integration-4`, host — `v=4`, FileIntake — `v=2`, CSS остаётся `v=3`: в браузере обнаруживался старый кеш под прежними URL.

INT-06 обновляет только изменённые входы: Hyperspace `integration-5`, Calendar `integration-6` и его private scene `v=2`. Остальной общий runtime и vendor не менялись.

### Уточнение порядка плана

Для Rays извлечение чистой сцены завершено. Для остальных семи выбран первый безопасный срез: общая UI-оболочка и команды, неизменные частные генераторы и renderer, тесты фактической генерации/экспорта. Переписывание всех p5/Canvas-моделей одновременно не требуется для централизованного UI. Дальнейшее извлечение engine выполняется отдельно, после приёмки, с сохранением fixtures. Общего «генератора всего» нет.

## По инструментам

### Rays Pattern

Canvas и SVG теперь читают `engine/scene.js` через `engine/renderers.js`. Семь golden-сценариев не перезаписаны. Сохранены разрешённые количества лучей, формулы, порядок примитивов, смещение рядов и историческое дублирование вертикального луча у чётных count.

Исправлены восстановление внешнего радиуса перед следующим изменением gap, потеря tone-параметров в image filename/storage, конфликт gradient/image флагов, URL cleanup и владение export shortcut. Общие панели Pattern/Tone/Settings, image intake с Remove, сводки и feedback подключены. Изображение не кодируется в filename: это по-прежнему не полный project round-trip.

INT-05: убран фиктивный src пустого превью, Reset очищает intake и отменяет позднюю загрузку. Read/decode/cancel guards покрыты отдельно. В браузере malformed SVG не заменяет прежний источник; повторный файл, Reset, `⌘E` и `⌘\` проверены. Rays принят.

### Random Lines

Общие Pattern/Tone/Settings; Generate остаётся явным. `sf` разбирается до `s`, scale больше не превращается в NaN из-за safe field. Добавлены empty/stale/ready состояния, фактическое число размещённых линий и сообщение о лимите; пустой/устаревший результат не экспортируется как готовый. Image intake умеет повторный файл, ошибки с сохранением прежнего источника и Remove. Геометрия, RNG и предел попыток не изменены.

Legacy gradient/image flags в этом приложении пока допускают совместное включение с приоритетом image и gradient fallback при отсутствии файла. Это отдельный остаток унификации выбора режима, не выданный за исправленный дефект.

INT-06: source/read/decode/cancel/rollback и fallback закреплены тестами; browser valid→broken→same→Remove и возврат выполнены. Миграция принята с сохранением исходных правил Tone.

### Pattern 02

Одна общая панель, SVG dock, Undo/Redo с единой клавиатурой. Исправлена история клавиатурных изменений слайдера; mouseup/touchend/touchcancel вне слайдера завершает транзакцию. Один владелец p5 canvas. SVG проверен по всем восьми комбинациям toggles и двум наборам параметров.

INT-06: отдельные транзакции мыши/клавиатуры подтверждены в браузере (50→71→72, Undo→71→50); touchcancel — эмуляцией. Миграция принята.

### Asterisk

Общие controls/panel/export. Исправлена лишняя нулевая копия в SVG axes mode: число кривых совпадает с preview при 0/1/2/7 слоях в обоих режимах, всех восьми масштабах 1:1–1:128 и обоих caps (128 комбинаций в автоматическом тесте). В INT-05 завершён browser stress на семи слоях, обоих режимах, крайних scale, caps и grid; два SVG проверены. Asterisk принят. Интенциональная модульная сетка по-прежнему входит в экспорт, в том числе сетки дубликатов при выключенном Show grid — это сохранённое правило формата, не новая WYSIWYG-опция. Синхронный максимум 100 слоёв не запускался и не объявлен безопасным.

### Pattern 01

Сохранены пять режимов, частные диапазоны, canvas и модели. Общий Mode/Pattern UI, один SVG export. Исправлены отсутствующий keyboard export Diagonal Grid и отсутствующий публичный `rectangleModule.exportSvg`. Магнитные шоткаты ограничены активным режимом и не перехватывают ввод. Выбранный режим имеет `aria-pressed`; аудитор проверяет его как выбранный переключатель, а не обычную кнопку.

Подгонка Diagonal Grid при resize меняет CSS-размеры, не буфер/прикреплённые точки. Для остальных режимов исходная регенерация при переключении/resize сохранена до решения пользователя. Не обещается сохранение случайной композиции между вкладками.

INT-06: два browser-прохода всех пяти режимов, корректные controls/canvas, тесты guards неактивного режима и ввода. Миграция принята.

### Hyperspace

Общая панель, реальные HSB-поля, PNG dock, Pause/resume по Space. UI-клики/drag не меняют vanishing point. Экспорт сохраняет состояния частиц и их собственные origins; ожидает PNG encoding перед удалением graphics. Legacy регенерация при resize пока сохранена.

INT-06: исправлена проверка центра до resize; Center/drag/pause/resize/возврат и новый PNG проверены. Миграция принята.

### Calendar Randomizer

Inline runtime извлечён в `script.js`. Шаблоны и обработчики имеют lifecycle: предыдущий XHR и подписки отменяются, поздний ответ не подменяет новый шаблон. Поиск artwork ограничен `#svg-container > svg`; иконки framework не рандомизируются. Четыре template сохранены, общий цветовой UI/команды подключены. 20 переключений не размножают Randomize-обработчик.

INT-06: private scene сохраняет базовые CSS/attribute transforms, defs/resources, none/url/alpha и стили экспорта; исправлены отмена XHR, BFCache rebind и readouts. Четыре шаблона плюс nested SVG fixture прошли проверки настоящего DOM. **Экспорт повторно рандомизирует композицию, как оригинал**, в том числе во время перехода; WYSIWYG не вводился. Миграция принята в объёме штатных шаблонов и проверенной fixture, не произвольного SVG.

### Chladni

Общие Pattern/Microphone панели и PNG dock. `CaptureSession` ждёт разрешения, объединяет повторный Start, допускает retry после отказа и выключает поздно предоставленный stream после Stop. Ручной X/Y редактируются независимо; отображаемые числа следуют программным изменениям p5 sliders. PNG использует последний реально отрисованный threshold/state и ждёт encoding.

Числовые FFT-последовательности, permission fake, start/stop/pause, статический рисунок и скачанный PNG проверены. В INT-07 устранён неверный Requesting после Stop, добавлены стадии запуска и четыре теста. **INT-08: после системного разрешения настоящий capture работает.** Проверены все четыре сочетания осей, pause/resume, два побайтно одинаковых PNG одного замороженного кадра, Stop/restart, уход и возврат без автостарта. Тестовая вкладка закрыта, пользовательская оставлена stopped. Отказ/поздний grant/точный нулевой сигнал проверены детерминированно, без отзыва системных разрешений. Нативный capture indicator не наблюдался; точные пределы проверки — в INT-08.

## Ограничения приёмки и необязательные улучшения

1. **Отдельная проблема браузерного окружения.** В INT-05 та же ошибка воспроизведена на пустом стенде без framework/p5/MutationObserver. Смена расположения скрытых iframe не устранила её полностью. Внешний дефект остаётся, но больше не блокирует все генераторы как предполагаемая ошибка их кода. Новые исключения и ошибки приложения по-прежнему блокируют его приёмку; ничего не подавлено. Доказательства и минимальный стенд — в INT-05.
2. **Границы аппаратной проверки Chladni.** Основная live-матрица закрыта в INT-08. Отказ/повтор после отказа, поздний grant и точная тишина покрыты тестами, не манипуляциями системным permission UI. Нативный индикатор микрофона не доступен автоматизации; cleanup подтверждается Stop/restart/уходом в браузере, тестами session и закреплённым p5 AudioIn.stop. Проверенный Back был повторной загрузкой; BFCache покрыт общими lifecycle-тестами.
3. **Необязательные изменения поведения.** Calendar current-frame export, сохранение композиции Pattern 01/Hyperspace при resize/tab и взаимоисключающий Tone Random Lines остаются отдельными возможными улучшениями. Для миграции сохранены оригинальные правила; эти решения больше не представлены как обязательные незакрытые этапы.
4. **T.7 закрыта у всех восьми новых инструментов.** Touchcancel проверен эмуляцией; общая мобильная приёмка новых инструментов не входит в объём. Особенности восстановления формы Calendar указаны в INT-06; полноценное project persistence не обещается.
