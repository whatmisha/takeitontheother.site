# Full SVG starter

This is the canonical full-feature SVG reference application for UI Garage. It
imports only `../../src/index.js` and contains no framework implementation.

Included workflows:

- declarative settings, sliders, toggles and unified color controls;
- deterministic SVG rendering, zoom, pan and fit;
- draggable/collapsible panels and global collapse shortcut;
- undo/redo, bundled and user presets, persistence and share URLs;
- validated JSON import with rollback plus JSON export;
- SVG, PNG and PDF export using local vendor libraries;
- file picker, dropzone, status, error and dialog states;
- keyboard help and canonical shortcuts;
- responsive mobile viewport coordination;
- symmetric destroy/re-init of application and public helper controllers.

Serve the UI Garage directory and open `starters/svg-full/`. Do not open the
HTML through `file://`.
