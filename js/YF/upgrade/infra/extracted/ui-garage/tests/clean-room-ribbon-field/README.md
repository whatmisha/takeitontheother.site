# Ribbon Field clean-room proof

This application was created from `START_HERE.md` and the full SVG starter. It
is a new deterministic wave generator, not a copy of an existing product. It
imports only the public `src/index.js` entry point and the documented CSS
contract.

The fixture exercises history, user and bundled presets, persistence, share
URLs, validated JSON round trips, file intake, panels, canonical shortcuts,
dialogs, lifecycle re-initialization, and SVG/PNG/PDF export. It deliberately
has no external runtime dependency.

Serve the UI Garage directory and open `tests/clean-room-ribbon-field/`.
