# Third-party licenses

The framework bundles browser runtime dependencies so copied tools do not need a
CDN. Exact versions are recorded in `vendor/VERSIONS.json`.

- jsPDF: `vendor/licenses/jspdf.txt`
- svg2pdf.js: `vendor/licenses/svg2pdf.js.txt`
- opentype.js: `vendor/licenses/opentype.js.txt`
- Paper.js: `vendor/paper/0.12.17/LICENSE.txt`

Framework fonts and their role are documented in `fonts/README.md`. This file is
an inventory, not a replacement for the bundled license texts.
