# Wander Pattern donor

`wander_bender/pattern` — v3-прототип Pattern Bender, основанный только на Random mode основного Wander Bender.

Можно использовать:

- defineTool configuration pattern;
- deterministic RNG;
- random ranges;
- физические SVG units;
- preset/share integration.

Нельзя использовать как замену основного Wander, поскольку основной инструмент обязан сохранить Radial, Random и Flow Field.
