# Baselines

Baseline-материалы фиксируют поведение оригинальных инструментов до копирования и рефакторинга.

- `TEST_BASELINES.md` — команды и результаты автоматических тестов.
- `VISUAL_BASELINES.md` — viewport, UI states и исходные визуальные наблюдения.
- `RUNTIME_BASELINES.md` — network, console, storage и runtime-зависимости.
- `donor-notes/` — различия источников, которые не являются текущим runtime.

Baseline нельзя обновлять автоматически в том же изменении, которое меняет UI или domain behavior.
