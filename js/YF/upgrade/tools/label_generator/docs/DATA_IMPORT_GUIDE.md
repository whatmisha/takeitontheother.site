# Руководство по импорту данных из Google Sheets

## Как работает система плейсхолдеров

В шаблонах стикеров вы можете использовать специальные плейсхолдеры для автоматической подстановки данных из Google Таблиц.

### Формат плейсхолдера

**Формат:** `БУКВА` + `трёхзначное число`

- **БУКВА** (A-Z) — колонка в таблице
- **Трёхзначное число** (001-999) — номер строки ВНУТРИ ячейки таблицы

### Примеры

- `A001` → Колонка A, строка 1 внутри ячейки
- `B002` → Колонка B, строка 2 внутри ячейки
- `C003` → Колонка C, строка 3 внутри ячейки

## Пример: Laptop Sticker

### Шаблон стикера содержит:

```json
{
  "texts": [
    {
      "content": "A001",           // Название продукта
    },
    {
      "content": "B001",           // Серийный номер
    },
    {
      "content": "C001\nC002\nC003\nC004",  // Многострочное описание
    },
    {
      "content": "Серийный номер: E001",  // Текст с плейсхолдером
    },
    {
      "content": "Дата изготовления: D001",  // Текст с плейсхолдером
    }
  ]
}
```

### Пример Google Таблицы

Создайте таблицу со следующей структурой:

| A (Название) | B (Серийный №) | C (Описание) | D (Дата) | E (S/N для метки) |
|--------------|----------------|--------------|----------|-------------------|
| Ноутбук Lunnen Ground 15.6"<br>Профессиональная работа<br>Игры в Full HD | LL5FAWG03 | Intel Core i5-1235U<br>16 GB RAM<br>512 GB SSD<br>Windows 11 Pro | 15.11.2024 | SN-2024-001 |
| Ноутбук Lunnen Air 14"<br>Легкий и компактный<br>Для путешествий | LL4AIRT12 | AMD Ryzen 7 5800U<br>8 GB RAM<br>256 GB SSD<br>Ubuntu 22.04 | 20.11.2024 | SN-2024-002 |

**Важно:** Для многострочного текста внутри одной ячейки используйте:
- **macOS/Windows:** `Alt + Enter` (Option + Enter на Mac)
- **Google Sheets:** `Cmd + Enter` (Mac) или `Ctrl + Enter` (Windows)

## Инструкция по использованию

### 1. Создайте Google Таблицу

1. Откройте [Google Sheets](https://docs.google.com/spreadsheets/)
2. Создайте новую таблицу
3. Заполните данные согласно вашему шаблону
4. **Важно:** Каждая строка таблицы = один стикер

### 2. Опубликуйте таблицу для просмотра

**Вариант A (рекомендуется):**
1. Нажмите `Файл` → `Опубликовать в веб`
2. Выберите нужный лист
3. Формат: `Веб-страница` или `CSV`
4. Нажмите `Опубликовать`
5. Скопируйте полученную ссылку

**Вариант B:**
1. Нажмите кнопку `Настройки доступа` (справа вверху)
2. Выберите `Доступ всем, у кого есть ссылка`
3. Права: `Читатель`
4. Скопируйте ссылку на таблицу

### 3. Загрузите данные в генератор

1. Откройте генератор стикеров
2. В панели **Data Import** вставьте ссылку на таблицу
3. Нажмите кнопку **Load Data**
4. Проверьте, что данные загрузились корректно

### 4. Генерация стикеров

**Экспорт текущего стикера:**
- Нажмите **Export Current Label** — экспортирует стикер с данными из первой строки таблицы

**Экспорт всех стикеров:**
- Нажмите **Generate All Labels** — создаст по одному SVG-файлу для каждой строки таблицы

## Поддерживаемые форматы ссылок

Генератор поддерживает следующие форматы URL:

1. **Обычная ссылка на таблицу:**
   ```
   https://docs.google.com/spreadsheets/d/SHEET_ID/edit...
   ```

2. **Опубликованная ссылка:**
   ```
   https://docs.google.com/spreadsheets/d/e/PUBLISHED_ID/pubhtml
   ```

3. **CSV ссылка:**
   ```
   https://docs.google.com/spreadsheets/d/SHEET_ID/export?format=csv&gid=0
   ```

Генератор автоматически конвертирует ссылку в формат CSV для загрузки данных.

## Возможные проблемы

### Ошибка загрузки данных

**Причины:**
- Таблица не опубликована для просмотра
- Неверный формат ссылки
- Проблемы с доступом к Google Sheets

**Решение:**
1. Убедитесь, что таблица опубликована или доступна по ссылке
2. Проверьте формат ссылки
3. Попробуйте использовать CSV ссылку напрямую

### Плейсхолдер не заменяется

**Причины:**
- Неверный формат плейсхолдера (должен быть `БУКВА` + `трёхзначное число`)
- Колонка не существует в таблице
- Номер строки превышает количество строк в ячейке

**Решение:**
1. Проверьте формат плейсхолдера
2. Убедитесь, что колонка существует в таблице
3. Проверьте количество строк в многострочной ячейке

## Технические детали

### Как работает парсер

1. **Загрузка CSV**: Генератор конвертирует ссылку на Google Sheets в CSV URL и загружает данные
2. **Парсинг**: CSV парсер корректно обрабатывает многострочные значения в кавычках
3. **Разбивка ячеек**: Каждая многострочная ячейка разбивается на массив строк
4. **Замена плейсхолдеров**: Регулярное выражение находит все плейсхолдеры формата `[A-Z]\d{3}` и заменяет их на соответствующие данные
5. **Генерация**: Для каждой строки таблицы генерируется отдельный SVG файл

### Логирование

Все операции логируются в консоль браузера (F12 → Console). Вы можете отслеживать:
- Загрузку данных
- Парсинг CSV
- Замену плейсхолдеров
- Генерацию файлов
