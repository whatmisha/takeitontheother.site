# Полноэкранный Canvas

## Изменения

Canvas теперь занимает всю ширину и высоту окна браузера для максимальной рабочей области.

## Что изменено

### 1. **body** - убран padding
```css
/* Было: */
padding: var(--spacing-3xl); /* ~20px отступы со всех сторон */

/* Стало: */
padding: 0; /* нет отступов */
```

### 2. **.container** - убрано ограничение ширины
```css
/* Было: */
max-width: 1400px; /* ограничение максимальной ширины */
margin: 0 auto;
height: calc(100vh - 2 * var(--spacing-3xl));

/* Стало: */
width: 100%; /* на всю ширину окна */
margin: 0;
height: 100vh; /* на всю высоту окна */
```

### 3. **.main-content** - добавлена высота
```css
/* Было: */
width: 100%;

/* Стало: */
width: 100%;
height: 100%; /* занимает всю доступную высоту */
flex: 1; /* растягивается */
```

### 4. **.canvas-container** - полноэкранный режим
```css
/* Было: */
border-radius: var(--radius); /* скругленные углы */
min-height: 400px;
margin: 0 auto;

/* Стало: */
border-radius: 0; /* без скруглений, edge-to-edge */
width: 100%;
height: 100%; /* на всю высоту */
```

## Результат

✅ Canvas занимает **100%** ширины окна
✅ Canvas занимает **100%** высоты окна
✅ Максимальная рабочая область для зума и панорамирования
✅ Нет видимых границ контейнера
✅ Edge-to-edge дизайн

## Пользовательский опыт

- **До**: Canvas был ограничен шириной 1400px с отступами по краям
- **После**: Canvas занимает весь экран, обеспечивая максимальную рабочую область

Панели управления остаются на своих местах (фиксированы по краям), но теперь canvas использует всё доступное пространство.

✅ Кнопки управления видны и доступны
