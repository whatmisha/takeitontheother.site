# Базовый зум как 100%

## Изменение

Теперь размер макета при загрузке (после fit to screen) считается за **100%**, а не реальный масштаб 1:1.

## Что изменилось

### Было:
- 100% = реальный размер макета (zoom = 1)
- Fit to screen мог давать, например, 23% или 147%
- Неинтуитивно для пользователя

### Стало:
- 100% = размер макета при загрузке (fit to screen)
- Fit to screen всегда дает 100%
- Интуитивно и удобно

## Как работает

### 1. При загрузке страницы:
```javascript
fitToScreen() {
    // ... вычисляем оптимальный масштаб ...
    this.zoom = scale; // например, 0.234
    this.baseZoom = this.zoom; // сохраняем как базовый
    // Индикатор покажет: 100%
}
```

### 2. При зуме:
```javascript
getZoomPercent() {
    return Math.round((this.zoom / this.baseZoom) * 100);
    // Если zoom = 0.468 и baseZoom = 0.234
    // Результат: 200%
}
```

### 3. При нажатии "Reset" (1:1 или Cmd+1):
```javascript
resetZoom() {
    this.zoomTo(this.baseZoom, centerX, centerY);
    // Возвращаемся к 100% (к размеру при загрузке)
}
```

## Примеры

### Сценарий 1: Загрузка страницы
1. Страница загружается
2. Автоматический fit to screen: реальный zoom = 0.234
3. **Индикатор показывает: 100%** ✅
4. Пользователь видит удобный размер и знает, что это "нормально"

### Сценарий 2: Приближение
1. Пользователь крутит колесо мыши (с Cmd)
2. Реальный zoom = 0.468
3. **Индикатор показывает: 200%** ✅
4. Понятно, что макет увеличен в 2 раза

### Сценарий 3: Reset
1. Пользователь нажимает кнопку "1:1" или Cmd+1
2. Zoom возвращается к baseZoom (0.234)
3. **Индикатор показывает: 100%** ✅
4. Возврат к комфортному размеру при загрузке

### Сценарий 4: Fit to Screen
1. Пользователь нажимает "Fit"
2. Пересчитывается оптимальный масштаб
3. Этот масштаб сохраняется как новый baseZoom
4. **Индикатор показывает: 100%** ✅

## UX преимущества

✅ **Интуитивно** - 100% это "нормальный" размер при загрузке
✅ **Предсказуемо** - всегда знаешь, что 100% это комфортный размер
✅ **Удобно** - reset возвращает к удобному размеру, а не к непонятному 1:1
✅ **Профессионально** - как в Figma и других профессиональных инструментах
