# Font Shaker - Инструмент для работы с вариативными шрифтами

Font Shaker — это интерактивный веб-инструмент для визуализации и анимации вариативных шрифтов, созданный для подготовки презентационных материалов.

## 🎯 Основные возможности

### 📝 Работа с текстом
- **Редактирование текста** — введите любой текст для отображения
- **Настройка размера** — от 50px до 1000px с точностью до пикселя
- **Поддержка многострочного текста**

### 🎨 Вариативные оси шрифта
Инструмент автоматически определяет оси вариативности шрифта и создает для каждой оси слайдер:
- **Weight (wght)** — толщина шрифта
- **Width (wdth)** — ширина шрифта
- И любые другие оси, определенные в шрифте

Для Lunnen Display Variable Font поддерживаются все доступные оси с их реальными диапазонами значений.

### 🖌️ Визуализация контуров

#### Фон
- Настройка цвета фона canvas
- HEX цветовой ввод с preview

#### Заливка текста
- Включение/выключение заливки
- Настройка цвета заливки
- Возможность работы только с контуром

#### Контур (Outline)
- Включение/выключение отображения контура
- Настройка цвета контура
- Регулировка толщины линии (0.5px - 10px)

#### Узловые точки (Anchor Points)
- Включение/выключение отображения
- Настройка цвета
- Регулировка размера (2px - 20px)
- **Три формы**: круг ●, квадрат ■, крест +

#### Направляющие точки (Handle Points)
- Включение/выключение отображения
- Настройка цвета
- Регулировка размера (1px - 15px)
- **Три формы**: круг ●, квадрат ■, ромб ◆
- Автоматическое отображение связующих линий между handle points и anchor points

### 🎭 OpenType Features

Поддержка основных OpenType фич:
- **liga** — Стандартные лигатуры (по умолчанию включено)
- **dlig** — Дискреционные лигатуры
- **salt** — Стилистические альтернативы
- **calt** — Контекстные альтернативы (по умолчанию включено)
- **kern** — Кернинг (по умолчанию включено)

### 🎬 Анимация

- **Включение/выключение анимации** — простой toggle
- **Выбор оси для анимации** — анимация по любой доступной оси
- **Настройка скорости** — от 0.5x до 10x
- **Плавная синусоидальная анимация** между минимальным и максимальным значениями оси
- **Зацикленная анимация** — идеально для записи скринкастов

### 💾 Экспорт

- **Export SVG** — сохранение в векторный формат
- Сохраняются все настройки:
  - Цвет фона
  - Заливка и цвет текста
  - Контур (если включен)
  - Узловые точки и направляющие (если включены)
  - Все OpenType фичи
  - Текущие значения вариативных осей
- Имя файла: `fontshaker-[timestamp].svg`

### 🔍 Zoom & Pan

- **Zoom**: Cmd+Scroll или кнопки ± в интерфейсе
- **Pan**: Space+Drag или Scroll (без Cmd)
- **Reset Zoom**: Cmd+0 или клик по индикатору zoom
- **Fit to Screen**: Cmd+1
- Индикатор zoom в верхнем меню

### 🎛️ Управление панелью

- **Сворачивание/разворачивание** панели управления
- **Перетаскивание** панели (drag & drop)
- **Сохранение позиции** между сеансами
- Адаптивный дизайн для разных экранов

## 🚀 Использование

### Быстрый старт

1. Откройте `fontshaker.html` в современном браузере
2. Введите текст в поле "Text"
3. Настройте оси вариативности с помощью слайдеров
4. Включите отображение контуров, узловых точек и направляющих
5. Настройте цвета под ваши нужды
6. Включите анимацию для демонстрации
7. Экспортируйте результат в SVG

### Запись скринкастов

1. Настройте желаемое отображение (текст, цвета, размер)
2. Включите отображение контуров и точек
3. Выберите ось для анимации (например, Weight)
4. Настройте скорость анимации
5. Включите анимацию
6. Запустите запись экрана (анимация зациклена)

### Подготовка статических изображений

1. Настройте все параметры
2. Отключите анимацию
3. Установите нужные значения осей вручную
4. Экспортируйте в SVG
5. Используйте SVG напрямую или конвертируйте в другие форматы

## ⌨️ Горячие клавиши

### Zoom & Navigation
- `Cmd/Ctrl + Scroll` — Zoom in/out
- `Cmd/Ctrl + 0` — Reset zoom to 100%
- `Cmd/Ctrl + 1` — Fit to screen
- `+` / `-` — Zoom in/out
- `Space + Drag` — Pan canvas

### Слайдеры
- `↑` / `↓` — Изменить значение на baseStep
- `Shift + ↑` / `Shift + ↓` — Изменить значение на shiftStep
- `Enter` — Применить введенное значение
- `Escape` — Отменить изменения

## 🎨 Рекомендации по дизайну

### Цветовые схемы

**Темная тема (по умолчанию)**
- Фон: `#000000`
- Текст: `#ffffff`
- Контур: `#00ffff` (cyan)
- Anchor points: `#ff0000` (red)

**Светлая тема**
- Фон: `#ffffff`
- Текст: `#000000`
- Контур: `#0066ff` (blue)
- Anchor points: `#ff0066` (magenta)
- Handle points: `#00cc66` (emerald)

**Высококонтрастная**
- Фон: `#000000`
- Текст: `#ffffff`
- Контур: `#ffff00` (yellow)
- Anchor points: `#ff00ff` (magenta)
- Handle points: `#00ffff` (cyan)

### Рекомендации по размерам

- **Для скринкастов**: 300-500px
- **Для детальной демонстрации контуров**: 400-800px
- **Для overview**: 150-250px
- **Anchor points**: 4-6px для нормального размера шрифта
- **Handle points**: 3-5px для нормального размера шрифта

## 🐛 Известные ограничения

1. **Производительность**: При очень большом количестве точек (сложные глифы) возможны задержки
2. **Вариативные оси**: Если шрифт не содержит таблицу `fvar`, используются стандартные оси
3. **OpenType фичи**: Некоторые продвинутые фичи могут не отображаться корректно
4. **Экспорт**: При экспорте font-variation-settings могут не работать в некоторых программах

## 💡 Советы и трюки

### Создание "путешествия" по осям

1. Откройте несколько окон браузера с Font Shaker
2. В каждом установите разные значения осей
3. Сделайте скриншоты
4. Создайте слайд-шоу или анимацию

### Демонстрация контуров

1. Отключите заливку текста
2. Включите контур с толщиной 2-3px
3. Включите anchor и handle points
4. Используйте контрастные цвета
5. Анимируйте по оси Weight для демонстрации изменений

### Подготовка материалов для документации

1. Используйте нейтральный фон (белый или черный)
2. Экспортируйте несколько вариантов с разными осями
3. Создайте сетку из экспортированных SVG
4. Добавьте подписи к каждому варианту
