# Font Shaker - Список файлов проекта

## Новые файлы

### Основные файлы инструмента

1. **fontshaker.html** (главный файл)
   - Полнофункциональный инструмент для работы с вариативными шрифтами
   - Визуализация контуров, узловых точек и направляющих
   - Система анимации по осям вариативности
   - Поддержка OpenType features
   - Экспорт в SVG
   - Размер: ~30KB

2. **guide.html** (быстрое руководство)
   - Интерактивное руководство по использованию
   - Сценарии использования
   - Рекомендуемые цветовые схемы
   - Горячие клавиши
   - Советы и трюки
   - Размер: ~15KB

3. **FONTSHAKER_README.md** (полная документация)
   - Подробное описание всех возможностей
   - Технические детали
   - Рекомендации по дизайну
   - Интеграция с другими инструментами
   - Известные ограничения
   - Размер: ~10KB

## Использование

### Быстрый старт
```bash
# Откройте файл в браузере
open fontshaker.html

# Или через guide для обучения
open guide.html
```

### Основные функции

**fontshaker.html** включает:
- ✅ Автоматическое определение осей вариативности
- ✅ Визуализация контуров шрифта (outline)
- ✅ Отображение узловых точек (anchor points)
- ✅ Отображение направляющих (handle points)
- ✅ Настройка цветов всех элементов
- ✅ Выбор формы точек (круг, квадрат, крест, ромб)
- ✅ OpenType features (liga, dlig, salt, calt, kern)
- ✅ Плавная анимация по любой оси
- ✅ Регулируемая скорость анимации
- ✅ Экспорт в SVG со всеми настройками
- ✅ Zoom & Pan (как в Figma)
- ✅ Клавиатурные shortcuts

## Возможности по файлам

### fontshaker.html

#### Панели управления
1. **Text Settings**
   - Ввод текста (textarea)
   - Размер шрифта (50-1000px)

2. **Variable Font Axes**
   - Динамически генерируемые слайдеры
   - Автоопределение осей из шрифта
   - Поддержка всех типов осей

3. **Appearance**
   - Background color
   - Text fill (с toggle)
   - Outline (цвет, толщина, toggle)
   - Anchor points (цвет, размер, форма, toggle)
   - Handle points (цвет, размер, форма, toggle)

4. **OpenType Features**
   - liga (стандартные лигатуры)
   - dlig (дискреционные лигатуры)
   - salt (стилистические альтернативы)
   - calt (контекстные альтернативы)
   - kern (кернинг)

5. **Animation**
   - Enable/disable toggle
   - Выбор оси для анимации
   - Скорость (0.5x - 10x)

#### SVG Canvas
- Размер: 2000×1000px
- Векторный zoom & pan
- Группы для текста и контуров
- Экспорт в SVG

#### Функции JavaScript
- `loadFont()` - загрузка и парсинг шрифта
- `createAxisSliders()` - создание слайдеров для осей
- `updateVisualization()` - обновление отображения
- `renderGlyphDetails()` - отрисовка контуров и точек
- `createPoint()` - создание точек разных форм
- `startAnimation()` / `stopAnimation()` - управление анимацией
- Экспорт SVG с сохранением всех настроек

### guide.html

#### Разделы
1. Быстрый старт
2. Основные возможности (с карточками)
3. Горячие клавиши (таблицы)
4. Цветовые схемы (с примерами)
5. Сценарии использования
6. Советы
7. Технические требования
8. Ссылки на ресурсы

## Использование с другими инструментами

### Figma/Sketch
1. Экспортируйте SVG из Font Shaker
2. Импортируйте в Figma/Sketch
3. Используйте как векторные элементы
4. Редактируйте цвета и композицию

### Adobe Illustrator
1. Откройте экспортированный SVG
2. Все пути сохранены
3. Редактируйте контуры
4. Сохраните в нужном формате

### Видеоредакторы
1. Запишите скринкаст с анимацией
2. Импортируйте в Premiere/Final Cut
3. Добавьте текст и эффекты
4. Экспортируйте финальное видео
