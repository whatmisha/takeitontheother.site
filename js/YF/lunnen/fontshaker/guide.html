Font Shaker Quick Guide

Интерактивный инструмент для визуализации и анимации вариативных шрифтов

🚀 Быстрый старт

  1. Откройте fontshaker.html в браузере
  2. Введите текст в поле "Text" (по умолчанию "Rg")
  3. Экспериментируйте со слайдерами вариативных осей
  4. Включите отображение контуров и точек
  5. Настройте цвета под ваши нужды
  6. Включите анимацию для демонстрации
  7. Экспортируйте результат в SVG
Открыть Font Shaker

✨ Основные возможности

📝 Редактирование текста

Введите любой текст для отображения. Поддерживается многострочный ввод. Размер от 50px до 1000px.

🎨 Вариативные оси

Автоматическое определение осей вариативности. Для каждой оси создается слайдер с реальными диапазонами значений.

🖌️ Контуры шрифта

Визуализация контуров, узловых точек (anchor points) и направляющих (handle points) с настройкой цветов и размеров.

🎭 OpenType фичи

Поддержка лигатур, кернинга, стилистических альтернатив и других OpenType features.

🎬 Анимация

Плавная анимация по любой оси вариативности. Регулируемая скорость от 0.5x до 10x. Зациклена для скринкастов.

💾 Экспорт SVG

Сохранение в векторный формат со всеми настройками: цвета, контуры, точки, значения осей.

📸 Сценарии использования

1. Запись скринкастов

  1. Настройте желаемое отображение (текст, цвета, размер)
  2. Включите отображение контуров и точек
  3. Выберите ось для анимации (например, Weight)
  4. Настройте скорость анимации (2-3x оптимально)
  5. Включите анимацию
  6. Запустите запись экрана (анимация автоматически зациклена)

2. Статические изображения для документации

  1. Используйте нейтральный фон (белый или черный)
  2. Настройте все параметры
  3. Отключите анимацию
  4. Установите нужные значения осей вручную
  5. Экспортируйте в SVG
  6. Конвертируйте SVG в нужный формат

3. Демонстрация контуров

  1. Отключите заливку текста
  2. Включите контур с толщиной 2-3px
  3. Включите anchor и handle points
  4. Используйте контрастные цвета
  5. Анимируйте по оси Weight для демонстрации изменений контуров

4. Сравнение значений осей

  1. Откройте несколько окон браузера с Font Shaker
  2. В каждом установите разные значения осей
  3. Расположите окна рядом
  4. Сделайте скриншот или запишите видео

💡 Советы

  • Производительность: При большом количестве точек отключите ненужные (handles или anchors)
  • Размеры точек: 4-6px для anchor points и 3-5px для handle points оптимально
  • Анимация: Скорость 2-3x идеальна для большинства демонстраций
  • Экспорт: SVG можно редактировать в Figma, Illustrator, Inkscape
  • Текст: Используйте "Rg" для демонстрации большинства характеристик шрифта
  • Цвета: При записи видео используйте высококонтрастные схемы

🔧 Технические требования

  • Браузеры: Chrome 90+, Firefox 88+, Safari 14+
  • Разрешение: Минимум 1280×720, рекомендуется 1920×1080
  • JavaScript: Должен быть включен
  • Подключение: Для загрузки opentype.js (CDN)
