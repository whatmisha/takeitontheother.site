# Wander Bender Generator

Генератор радиальных геометрических форм с толстыми обводками и тонкими контрформами.

## 🏗️ Архитектура

### Структура проекта
```
js/
├── wander-bender.js       # Главный файл, координация UI и режимов
├── modes/                 # Режимы генерации
│   ├── BaseMode.js       # Базовый класс для всех режимов
│   ├── RadialMode.js     # Радиальное распределение
│   ├── RandomMode.js     # Случайное распределение
│   └── FlowFieldMode.js  # Распределение по полю Perlin Noise
├── utils/                 # Утилиты
│   ├── DebounceUtils.js  # Debouncing для оптимизации
│   ├── ShapeGenerator.js # Генерация форм из линий
│   ├── Renderer.js       # Рендеринг SVG элементов
│   ├── PaperUtils.js     # Утилиты Paper.js (Boolean операции)
│   └── SpatialHash.js    # Spatial hashing для коллизий
└── ui/                    # UI компоненты (SliderController, ZoomPan, etc.)
```

## 🎨 Режимы генерации

### Radial Mode
Лучи расходятся из центральной точки с равными интервалами.
- Параметры: количество лучей, вращение лучей

### Random Mode
Случайное размещение элементов в заданной области.
- Параметры: количество, размер области, вариация длины, seed

### Flow Field Mode
Элементы следуют за полем Perlin Noise.
- Параметры: плотность, масштаб поля, влияние поля, spacing
- Оптимизация: Spatial Hash для быстрой проверки коллизий

## 🚀 Производительность

### Оптимизации:
- **Debouncing** - разные задержки для разных типов параметров (50ms/100ms/200ms)
- **Кэширование параметров** - элементы пересоздаются только при изменении параметров
- **Spatial Hash** - O(1) проверка коллизий вместо O(n²) для Flow Field
- **Batch DOM операции** - минимизация reflow/repaint

## 💡 Ключевые принципы

### Графика:
- Толстая обводка (45px) создает тонкую контрформу (10px)
- Boolean Union - все элементы объединяются перед применением обводки
- Интерактивная экстракция - клик на элемент "вытаскивает" его из группы

### Архитектура:
- Модульность - каждый режим в отдельном файле
- Расширяемость - новые режимы наследуются от `BaseMode`
- Разделение ответственности - генерация, рендеринг, утилиты отделены

## 📦 Зависимости

- Paper.js - для Boolean операций (unite/subtract)
- YF UI Framework - слайдеры, панели, zoom/pan

## 🔧 Добавление нового режима

1. Создать класс в `js/modes/`, наследующий от `BaseMode`
2. Реализовать методы `generate()` и `render()`
3. Зарегистрировать режим в `WanderBenderGenerator.modes`
4. Добавить UI элементы в `index.html`
