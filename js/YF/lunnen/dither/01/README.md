# Dithering Tool 🎨

Полнофункциональный веб-инструмент для применения эффекта дизеринга (dithering) к изображениям. Создан как альтернатива [tooooools.app/effects/dithering](https://www.tooooools.app/effects/dithering).

## 🌟 Возможности

### Алгоритмы дизеринга
- **Floyd-Steinberg** — алгоритм диффузии ошибок, создающий плавные, органичные паттерны
- **Bayer** — упорядоченный дизеринг с характерной сетчатой структурой
- **Random** — случайный дизеринг для создания зернистого эффекта

### Предобработка изображения
- **Blur (Размытие)** — смягчение резких переходов
- **Grain (Зернистость)** — добавление шума
- **Gamma (Гамма)** — коррекция яркости средних тонов
- **Black Point** — настройка черной точки
- **White Point** — настройка белой точки

### Настройки эффекта
- **Pixel Size** — размер пикселей для более грубого/тонкого эффекта
- **Threshold** — порог для определения границы между светлыми и темными областями
- **Color Mode** — три режима:
  - Монохром (черно-белый)
  - Градации серого (4 уровня)
  - Цветной

### Удобство использования
- 🖱️ Drag & Drop — перетаскивание файлов
- ⌨️ Горячие клавиши:
  - `Ctrl/Cmd + O` — открыть файл
  - `Ctrl/Cmd + S` — экспортировать результат
- 📱 Адаптивный дизайн
- 🎨 Современный UI с градиентами

## 🚀 Использование

1. Откройте `index.html` в браузере
2. Загрузите изображение (кнопка или drag & drop)
3. Настройте параметры в правой панели
4. Экспортируйте результат

## 🎯 Как работают алгоритмы

### Floyd-Steinberg Dithering
Алгоритм диффузии ошибок, который распределяет ошибку квантизации на соседние пиксели:
```
       * 7/16
3/16 5/16 1/16
```

### Bayer Dithering
Использует предопределенную матрицу 8×8 для упорядоченного дизеринга, создавая характерный сетчатый паттерн.

### Random Dithering
Применяет случайный порог к каждому пикселю, создавая шумовой эффект.

## 🎨 Примеры использования

- **Печатная графика** — имитация газетной печати
- **Художественные эффекты** — стилизация под различные техники
- **Оптимизация изображений** — уменьшение количества цветов
