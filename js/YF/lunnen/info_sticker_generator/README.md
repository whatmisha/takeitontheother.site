# Info Sticker Generator

Генератор информационных стикеров на основе модульной сетки Lunnen.

## Описание

Инструмент для создания макетов информационных стикеров с автоматической модульной сеткой. Идеален для создания стикеров на упаковку с точным соблюдением модульной системы.

## Основные возможности

- **Модульная сетка**: Автоматический расчет сетки на основе заданного модуля
- **Колонки**: Настраиваемое количество колонок с автоматическими отступами
- **Baseline Grid**: Точная вертикальная ритмика для выравнивания элементов
- **Экспорт в SVG**: Файлы с точными размерами в миллиметрах для Adobe Illustrator
- **Адаптивный цвет сетки**: Автоматическая подстройка контрастности сетки под цвет фона

## Параметры по умолчанию

- **Размеры**: 120×25 мм
- **Поля**: 3 мм
- **Колонки**: 3
- **Модули baseline**: 6
- **Модуль**: 4.1667 мм (автоматически рассчитывается)

## Интерфейс

### Панель Dimensions (слева)
- **Width**: Ширина стикера в миллиметрах
- **Height**: Высота стикера в миллиметрах
- **Background Color**: Цвет фона с HSB пикером

### Панель Grid (справа)
- **Module**: Базовая единица сетки в миллиметрах
- **Margins**: Отступы от краёв в миллиметрах
- **Columns**: Количество колонок
- **Baseline Modules**: Количество модулей для baseline grid

## Модульная система

Модуль — это базовая единица измерения, от которой зависят все параметры сетки:
- Минимальный шаг baseline grid = 1 модуль
- Отступы между колонками = 1 модуль
- Поля = настраиваются в миллиметрах

### Расчёт ширины колонки

```
Доступная ширина = Общая ширина - 2 × Поля
Суммарные отступы = (Количество колонок - 1) × Модуль
Ширина колонки = (Доступная ширина - Суммарные отступы) / Количество колонок
```

## Горячие клавиши

- **Cmd/Ctrl + E** — Экспорт SVG
- **Arrow keys** — Изменение значений слайдеров
- **Shift + Arrow keys** — Изменение с большим шагом

## Экспорт

При экспорте создаётся SVG файл с:
- Точными размерами в миллиметрах
- Корректными атрибутами для Adobe Illustrator
- Всеми элементами сетки (колонки, baseline, рамка)
- Настроенным цветом фона

Файл готов к открытию в Adobe Illustrator и использованию в производстве.

## Технические детали

### Структура проекта

```
info_sticker_generator/
├── index.html          # HTML структура
├── style.css           # Стили интерфейса
├── script.js           # Главный скрипт
├── fonts/              # Шрифты TT Commons Classic
└── src/                # Модули
    ├── core/           # Базовые классы (Settings, Constants)
    ├── grid/           # Сетка (GridCalculator, GridRenderer)
    ├── ui/             # UI контроллеры (SliderController, ColorPicker, PanelManager)
    ├── svg/            # Экспорт SVG
    └── utils/          # Утилиты (ColorUtils, MathUtils, DOMUtils)
```

### Модули

- **Settings**: Управление настройками
- **GridCalculator**: Расчёты модульной сетки
- **GridRenderer**: Отрисовка сетки в SVG
- **SliderController**: Управление слайдерами
- **ColorPicker**: HSB цветовой пикер
- **PanelManager**: Управление панелями (сворачивание, перетаскивание)
- **SVGExporter**: Экспорт в SVG файл

## Разработка

Инструмент построен на чистом JavaScript с использованием ES6 модулей. Не требует сборки или дополнительных зависимостей.
