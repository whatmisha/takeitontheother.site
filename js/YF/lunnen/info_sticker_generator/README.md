## 🍕 Pizza Boxer

**Lunnen Grid Generator** — это инструмент для создания модульных сеток, основанный на концепции "коробки для пиццы":

### Как это работает:

1. **Размеры коробки** (Front Width × Front Height)
   - Определяют размер рабочей области
   - Как коробка, которая содержит вашу "пиццу" (контент)

2. **Модульная сетка** (Grid Module)
   - Делит коробку на равные части
   - Как разрезанная пицца на кусочки одинакового размера
   - Модуль — это базовая единица измерения

3. **Строки и колонки** (Rows × Columns)
   - Вертикальные и горизонтальные направляющие
   - Помогают размещать элементы точно по сетке
   - Как решетка на коробке для пиццы

4. **Baseline Grid** (Базовая линия)
   - Ритм для размещения текста
   - Все строки текста выравниваются по базовой линии
   - Создает визуальную гармонию

5. **Link Mode** (Режимы связи)
   - **Off** - независимое управление всеми параметрами
   - **Rows × Height** - связь между количеством строк и высотой
   - **Module** - автоматический расчет модуля из размеров

### Философия:

Как коробка для пиццы создана идеально под размер пиццы и делит её на равные кусочки, 
так и модульная сетка создаёт идеальную структуру для размещения контента с математической точностью.

**Результат:** Гармоничный, сбалансированный дизайн, где каждый элемент находится на своём месте.

## 🏗️ Архитектура

### Модульная структура:

Проект разделен на **20 независимых модулей** в папке `src/`:

#### 🔧 core/ - Ядро
- **Settings.js** - Реактивное управление настройками
- **Constants.js** - Константы приложения

#### 🎨 utils/ - Утилиты
- **ColorUtils.js** - Конвертация цветов (hex, rgb, hsb)

- **GridCalculator.js** - Расчеты сетки
- **GridRenderer.js** - Отрисовка сетки

#### 📤 svg/ - SVG экспорт
- **SVGExporter.js** - Экспорт в SVG и JSON
- **SVGUtils.js** - Утилиты для SVG

#### 🎛️ ui/ - Интерфейс
- **SliderController.js** - Управление слайдерами
- **ColorPicker.js** - HSB color picker
- **PanelManager.js** - Drag & drop панелей
- **DragDropManager.js** - Базовый drag & drop

#### 📝 elements/ - Элементы
- **TextBlockManager.js** - Управление текстом
- **TextRenderer.js** - Отрисовка текста
- **GraphicsManager.js** - Управление графикой
- **GraphicsRenderer.js** - Отрисовка графики
- **ElementsNavigator.js** - Навигатор элементов

## 🔧 Разработка

### Структура кода:

```javascript
// Оркестратор (script.js)
class GridGenerator {
    constructor() {
        this.initializeModules();
    }
    
    initializeModules() {
        // Создание экземпляров модулей
        this.settings = new Settings();
        this.gridCalculator = new GridCalculator(this.settings);
        this.gridRenderer = new GridRenderer(this.settings, this.gridCalculator);
        // ... остальные модули
    }
    
    // Только методы координации!
}
```

### Добавление нового модуля:

1. Создать файл в `src/`
2. Импортировать в `script.js`
3. Инициализировать в `initializeModules()`
4. Использовать в методах координации
