Info Sticker Generator

Генератор информационных стикеров на основе модульной сетки Lunnen.

Размеры

Width и Height задают размеры стикера в миллиметрах.

Модульная сетка

Module (в мм) — базовая единица сетки. Управляет:

  • Baseline Grid — минимальный шаг сетки
  • Spacing — отступы между колонками
  • Margins — отступы от краёв

Колонки и бейслайн

Columns — вертикальные деления с отступами между ними.

Baseline — сетка для выравнивания по вертикали.

Экспорт SVG

Нажмите Export SVG для загрузки сетки. Файл открывается в Adobe Illustrator с точными размерами в миллиметрах.

Горячие клавиши

  • Cmd/Ctrl + E — Экспорт SVG
  • Arrow keys — Изменение значений слайдеров
  • Shift + Arrow keys — Изменение с большим шагом
