# Быстрый старт

## Запуск инструмента

### Вариант 1: Локальный сервер (рекомендуется)

Для корректной работы ES6 модулей необходим локальный сервер:

```bash
# Перейдите в папку проекта
cd info_sticker_generator

# Запустите локальный сервер (Python 3)
python3 -m http.server 8000

# Или используйте PHP
php -S localhost:8000

# Или используйте Node.js (если установлен npx)
npx serve
```

Откройте в браузере: http://localhost:8000

### Вариант 2: Через основной сервер проекта

Если проект уже запущен на сервере, откройте:
http://localhost:[PORT]/js/YF/lunnen/info_sticker_generator/

## Первый запуск

1. Откройте инструмент в браузере
2. Вы увидите стикер 120×25 мм с модульной сеткой
3. Используйте панели слева и справа для настройки параметров
4. Нажмите "Export SVG ⌘E" для экспорта

## Быстрая настройка

### Изменение размеров
- **Width**: Установите нужную ширину (50-300 мм)
- **Height**: Установите нужную высоту (10-100 мм)

### Настройка сетки
- **Module**: Базовая единица (автоматически рассчитывается для baseline)
- **Margins**: Отступы от краёв в миллиметрах
- **Columns**: Количество колонок (1-12)
- **Baseline Modules**: Количество модулей по высоте (1-20)

### Цвет фона
1. Кликните на цветной круг или введите HEX код
2. Используйте HSB слайдеры для точной настройки
3. Сетка автоматически подстроится под контрастность фона

## Экспорт

Нажмите **Export SVG** или **Cmd/Ctrl + E**

Файл сохранится как `sticker_[ширина]x[высота]mm.svg` и будет готов для:
- Adobe Illustrator
- Sketch
- Figma (импорт)
- Печати

## Горячие клавиши

- `Cmd/Ctrl + E` — Экспорт SVG
- `↑↓←→` — Изменение значений слайдеров
- `Shift + ↑↓←→` — Изменение с большим шагом
- `?` — Открыть справку

## Решение проблем

### Не работают ES6 модули
- Убедитесь, что используете локальный сервер (не file://)
- Проверьте консоль браузера на ошибки CORS

### Сетка не видна
- Проверьте чекбоксы "Columns" и "Baseline" в панели Grid
- Попробуйте изменить цвет фона для контраста

### Экспорт не работает
- Проверьте консоль браузера на ошибки
- Убедитесь, что браузер разрешает скачивание файлов
