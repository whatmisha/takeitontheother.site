Backup 03 - Pulsar Coder
Дата: 18 декабря 2025

Изменения в этой версии:
- Добавлена возможность перемещения центра схождения лучей
  * Drag мышью по canvas для перемещения центра
  * Концы лучей остаются на своих местах (фиксированы)
  * Короткие линии двигаются вместе с лучами
  * Убрана необходимость нажатия Shift
  * Курсор показывает grab/grabbing
- Добавлена кнопка "Reset Center" на панель Main
- Добавлен чекбокс "Show Rays" для скрытия длинных лучей
- Короткие линии остаются видимыми при скрытии лучей
- Референсный луч без коротких линий
- Референсный луч всегда горизонтален (на 3 часа, 0°)
- Короткие линии начинаются на разных расстояниях от центра
- Короткие линии могут находиться в любом месте луча (от 15px до 90% длины)

Техническая реализация:
- Фиксация конечных точек лучей при первой генерации
- Пересчет углов и длин при драге центра
- Сохранение endpoints для корректного перемещения
- Real-time обновление при изменении параметров
