# Backup Instructions

## Как делать бэкапы

1. Создать новую папку с номером (02, 03, 04...)
2. Скопировать все файлы проекта в эту папку
3. Исключить папку `_backup` из копирования

## Команда для бэкапа

```bash
# Найти следующий номер
NEXT=$(ls -d [0-9][0-9] 2>/dev/null | tail -1 | awk '{printf "%02d", $1+1}')

# Создать папку
mkdir -p "$NEXT"

# Скопировать все кроме _backup
rsync -av --exclude='_backup' . "$NEXT/"
```

Или вручную:
- Создать папку `02`, `03` и т.д.
- Скопировать все файлы проекта
- Не копировать папку `_backup`
