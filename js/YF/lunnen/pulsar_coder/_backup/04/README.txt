Backup 04 - Pulsar Coder
Дата: 18 декабря 2025

Изменения в этой версии:
- Исправлена проблема с прыжками коротких линий при драге центра
  * Сохранение fixedRayOffsets для предотвращения пересчета позиций
  * Короткие линии остаются на своих местах при перемещении центра
- Добавлена защита от выхода коротких линий за пределы лучей
  * Проверка dist > rayLengths[rayIndex] перед рисованием
  * Линии за пределами луча не рисуются
- Исправлена проблема с перемещением панели Main
  * Убран класс controls-panel-left с фиксированным left
  * Панель теперь может перемещаться свободно по всей странице
- Ray Length по умолчанию изменен с 350 на 250
- Добавлена возможность скрытия длинных лучей (чекбокс Show Rays)
- Добавлена возможность перемещения центра схождения лучей
  * Drag мышью по canvas для перемещения центра
  * Концы лучей остаются на своих местах (фиксированы)
  * Кнопка Reset Center для возврата в исходное положение
- Референсный луч без коротких линий
- Референсный луч всегда горизонтален (на 3 часа, 0°)
- Короткие линии начинаются на разных расстояниях от центра
- Короткие линии могут находиться в любом месте луча (от 15px до 90% длины)

Техническая реализация:
- Фиксация конечных точек лучей (fixedRayEndpoints)
- Фиксация позиций коротких линий (fixedRayOffsets)
- Пересчет углов и длин при драге центра
- Сохранение endpoints и offsets для корректного перемещения
- Real-time обновление при изменении параметров
