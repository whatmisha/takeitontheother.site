How it Works?

This tool generates packaging layout grids for use in Adobe Illustrator.

The layout shows an unfolded box with five panels:

  • Front - The main front panel of the box
  • Left/Right - Side panels (vertical)
  • Top/Bottom - Top and bottom flaps (horizontal)

Adjust the Front Panel Size to set the width and height of the main panel. The side panels will automatically adjust their length to match.

Set the Side Panel Thickness to control how wide the side, top, and bottom panels are.

All dimensions are in millimeters for print accuracy. The preview automatically scales to fit your screen.

Click Export SVG to download the grid as a vector file ready for Adobe Illustrator.
