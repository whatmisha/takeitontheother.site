# UI улучшения

## Изменения

### 1. ✅ Увеличены вертикальные отступы для fit to screen

**Было:** 80px сверху и снизу
**Стало:** 120px сверху и снизу

```javascript
const paddingVertical = 120; // было 80
```

Теперь макет загружается с более комфортными вертикальными отступами.

### 2. ✅ Улучшен стиль кнопок экспорта

#### Убрана обводка:
```css
/* Было: */
border: 1px solid var(--color-text);

/* Стало: */
border: none;
```

#### Изменен hover стиль:
```css
/* Было: */
.btn-export:hover {
    background: var(--color-bg); /* черный */
    color: var(--color-text);
}

/* Стало: */
.btn-export:hover {
    background: #2a2a2a; /* темно-серый */
    color: var(--color-text); /* белый */
}
```

### Кнопки экспорта:
- **По умолчанию**: белый фон, черный текст
- **При ховере**: темно-серый фон (#2a2a2a), белый текст
- **Без обводки**: чистый современный вид

## Преимущества

✅ **Больше воздуха** - увеличенные вертикальные отступы (120px)
✅ **Чище интерфейс** - нет лишних обводок на кнопках
✅ **Лучший контраст** - темно-серый hover вместо черного
✅ **Современный вид** - минималистичный дизайн
