# Улучшения Baseline и панели Grid

## Изменения

### 1. ✅ Добавлен модуль в свернутую панель Grid

**Было:**
```
Grid  Col 12  •  Row 19
```

**Стало:**
```
Grid  3.31 mm  •  Col 12  •  Row 19
```

Теперь в свернутом виде панели Grid показываются три ключевых параметра:
- **Модуль (Mod)** - базовая единица сетки в мм
- **Колонки (Col)** - количество колонок
- **Строки (Row)** - количество строк

### 2. ✅ Фиксированная толщина линий baseline при зуме

**Проблема:** При зуме линии baseline становились слишком жирными и мешали работе

**Решение:** Добавлен атрибут `vector-effect="non-scaling-stroke"` ко всем элементам baseline

Теперь толщина линий baseline остается **постоянной** независимо от уровня зума.

## Технические детали

### 1. Модуль в панели Grid

**Файл:** `script.js`

**Метод:** `updatePanelParams()`

```javascript
// Было:
gridParams.textContent = `Col ${col}  •  Row ${row}`;

// Стало:
const mod = this.settings.gridModule.toFixed(2);
gridParams.textContent = `${mod} mm  •  Col ${col}  •  Row ${row}`;
```

Модуль отображается с точностью до 2 знаков после запятой.

### 2. Non-scaling stroke для baseline

**Файл:** `src/grid/GridRenderer.js`

**Что изменено:**
- `drawBaseline()` - основная панель
- `drawBaselineVerticalLeftRight()` - боковые панели (левая/правая)
- `drawBaselineTopBottom()` - боковые панели (верхняя/нижняя)

**Добавленный атрибут:**
```javascript
'vector-effect': 'non-scaling-stroke'
```

Этот SVG атрибут указывает браузеру НЕ масштабировать толщину обводки при изменении viewBox (зуме).

## Преимущества

### Модуль в панели:
✅ **Больше информации** - сразу видны все ключевые параметры
✅ **Удобно** - не нужно раскрывать панель чтобы узнать модуль
✅ **Последовательность** - модуль это основа, логично что он первый

### Non-scaling stroke:
✅ **Читаемость** - линии не мешают при зуме
✅ **Профессионально** - как в Figma и Illustrator
✅ **Предсказуемо** - толщина всегда одинаковая
✅ **Удобно** - можно сильно зумировать без визуального шума

## Как работает vector-effect

SVG атрибут `vector-effect="non-scaling-stroke"` указывает браузеру применять stroke-width в координатах экрана, а не в координатах SVG viewBox.

**Без атрибута:**
- stroke-width: 0.5 при zoom 1x → 0.5px на экране
- stroke-width: 0.5 при zoom 2x → 1.0px на экране (масштабируется!)

**С атрибутом:**
- stroke-width: 0.5 при zoom 1x → 0.5px на экране
- stroke-width: 0.5 при zoom 2x → 0.5px на экране (НЕ масштабируется!)
