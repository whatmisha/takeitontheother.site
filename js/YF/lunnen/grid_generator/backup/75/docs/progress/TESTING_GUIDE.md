# 🧪 Руководство по тестированию

## Быстрый старт

1. **Запустите сервер** (если еще не запущен):
```bash
python3 -m http.server 8000
```

2. **Откройте в браузере**:
```
http://localhost:8000
```

3. **Откройте консоль разработчика** (F12 или Cmd+Option+I)

## 🐛 Известные ограничения

1. **Undo/Redo** - пока не реализовано (заготовка есть)
2. **Drag & Drop объектов** - частично реализовано, требует доработки
3. **Панель редактирования текста** - требует интеграции с новым менеджером
4. **Загрузка пользовательских SVG** - требует доработки UI

## 🔍 Проверка производительности

### Открыть Performance Monitor:

1. DevTools → Performance
2. Start Recording
3. Изменить несколько слайдеров
4. Stop Recording

**Ожидаемо:**
- Отрисовка < 16ms (60 FPS)
- Нет memory leaks
- Плавная анимация
