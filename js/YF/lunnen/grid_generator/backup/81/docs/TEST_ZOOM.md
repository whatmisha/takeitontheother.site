# Тестирование Zoom & Pan

## Как протестировать

Сервер запущен на http://localhost:8000

### Чек-лист тестирования

#### ✅ Zoom (Масштабирование)

1. **Колесо мыши**
   - [ ] Прокрутка вверх - приближает
   - [ ] Прокрутка вниз - отдаляет
   - [ ] Зум происходит с центром на курсоре
   - [ ] Индикатор зума обновляется

2. **Кнопки**
   - [ ] Кнопка "+" увеличивает зум
   - [ ] Кнопка "-" уменьшает зум
   - [ ] Кнопка с квадратом (Fit) подгоняет под экран
   - [ ] Кнопка "1:1" сбрасывает в 100%

3. **Клавиатура**
   - [ ] Cmd/Ctrl + Plus увеличивает
   - [ ] Cmd/Ctrl + Minus уменьшает
   - [ ] Cmd/Ctrl + 0 подгоняет под экран
   - [ ] Cmd/Ctrl + 1 сбрасывает в 100%

4. **Индикатор**
   - [ ] Показывает текущий зум в процентах
   - [ ] Двойной клик сбрасывает в 100%
   - [ ] При наведении подсвечивается

#### ✅ Pan (Панорамирование)

1. **Пробел + drag**
   - [ ] При нажатии пробела курсор меняется на "grab"
   - [ ] При перетаскивании курсор меняется на "grabbing"
   - [ ] Canvas перемещается вместе с мышью
   - [ ] После отпускания пробела курсор возвращается

2. **Средняя кнопка мыши**
   - [ ] При нажатии средней кнопки начинается панорамирование
   - [ ] Canvas перемещается плавно
   - [ ] Контекстное меню не появляется

3. **Блокировка на input**
   - [ ] В текстовых полях пробел вводит пробел (не включает pan)
   - [ ] После выхода из input пробел работает для pan

#### ✅ UI/UX

1. **Визуал**
   - [ ] Панель зума видна внизу по центру
   - [ ] Кнопки реагируют на hover
   - [ ] Анимации плавные
   - [ ] Стили соответствуют общему дизайну

2. **Производительность**
   - [ ] Зум плавный без тормозов
   - [ ] Pan плавный без тормозов
   - [ ] Нет задержек при взаимодействии

3. **Граничные случаи**
   - [ ] Минимальный зум (10%) работает
   - [ ] Максимальный зум (1000%) работает
   - [ ] Fit to screen с разными размерами canvas
   - [ ] Pan за пределы canvas работает

#### ✅ Совместимость с существующей функциональностью

1. **Слайдеры**
   - [ ] Работают с зумом
   - [ ] Стрелки клавиатуры не конфликтуют с зумом

2. **Панели**
   - [ ] Можно перетаскивать (не конфликтует с pan)
   - [ ] Коллапс работает

3. **Экспорт**
   - [ ] SVG экспортируется в реальных размерах (не зависит от зума)
   - [ ] Настройки экспортируются

4. **Объекты**
   - [ ] Текст и графика отображаются правильно при зуме
   - [ ] Можно добавлять новые объекты

## Известные ограничения

- Pinch-to-zoom на тачпадах пока не поддерживается
- Анимация при fit/reset не добавлена (можно добавить в будущем)
