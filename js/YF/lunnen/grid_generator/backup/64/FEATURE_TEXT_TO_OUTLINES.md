# Экспорт текста в кривых (Convert Text to Outlines)

## Описание

Добавлена возможность экспорта SVG с текстом, конвертированным в кривые (paths). Это полезно когда:
- Нужно открыть файл на другом компьютере без установленных шрифтов
- Требуется избежать проблем с отсутствующими шрифтами в Adobe Illustrator или других графических редакторах
- Необходимо передать макет в печать без риска подмены шрифтов

## Как использовать

1. Настройте макет как обычно
2. Перед экспортом установите чекбокс **"Convert text to outlines"** под кнопкой "Export SVG"
3. Нажмите **Export SVG** (⌘E)
4. Приложение автоматически:
   - Загрузит библиотеку opentype.js (если еще не загружена)
   - Загрузит необходимые шрифты
   - Конвертирует все текстовые элементы в SVG paths
   - Скачает готовый файл

## Технические детали

### Поддерживаемые шрифты

- **TT Commons Classic** (Regular 400, Medium 500)
- **Lunnen Display** (Variable 100-400)

### Что конвертируется

- Все `<text>` элементы в SVG
- Сохраняются все атрибуты: цвет, прозрачность, трансформации
- Учитывается межбуквенное расстояние (letter-spacing) с правильной обработкой отрицательных значений
- Применяется кернинг для каждой пары символов
- Посимвольная отрисовка для точного позиционирования

### Производительность

- Первый экспорт может занять 2-3 секунды (загрузка библиотеки и шрифтов)
- Последующие экспорты будут быстрее (шрифты кэшируются)
- При большом количестве текста экспорт может занять до 5-10 секунд

### Устранение неполадок

**Проблема:** Экспорт не работает или текст не конвертируется
- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что есть доступ к интернету (для загрузки opentype.js)
- Проверьте, что файлы шрифтов находятся в папке `fonts/`

**Проблема:** Неправильное отображение конвертированного текста
- Проверьте, что используемый шрифт поддерживается (см. список выше)
- Убедитесь, что font-weight соответствует доступным начертаниям

## Архитектура

### Новые файлы

- `src/utils/TextToPath.js` - Утилита для конвертации текста в paths

### Изменения в существующих файлах

- `index.html` - Добавлен чекбокс для опции конвертации
- `style.css` - Стили для новой группы экспорта
- `src/svg/SVGExporter.js` - Добавлена поддержка async экспорта с конвертацией
- `script.js` - Инициализация TextToPath и передача опций в exporter

### Зависимости

- **opentype.js** (v1.3.4) - загружается динамически через CDN

## Примечания

- Конвертация необратима - сохраните копию с редактируемым текстом через "Export Setup"
- Размер файла с кривыми будет больше, чем с текстом
- Для редактирования текста используйте импорт настроек из JSON
