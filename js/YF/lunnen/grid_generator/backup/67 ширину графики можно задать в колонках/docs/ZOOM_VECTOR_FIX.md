# Исправление: Векторный зум вместо растрового

## Проблема

При первоначальной реализации зум использовал CSS `transform: scale()` для масштабирования wrapper элемента, содержащего SVG. Это приводило к тому, что браузер масштабировал уже растеризованное изображение, что вызывало размытие при приближении, несмотря на то, что содержимое является векторным.

### Симптомы:
- ❌ Размытие при приближении
- ❌ Потеря четкости линий и текста
- ❌ Видны пиксели/артефакты

## Решение

Переработана система зума для использования SVG `viewBox` вместо CSS `transform`. Это обеспечивает настоящее векторное масштабирование.

### Ключевые изменения:

#### 1. Удален wrapper с CSS transform
```javascript
// БЫЛО (неправильно):
transform = `translate(${panX}px, ${panY}px) scale(${zoom})`;
wrapper.style.transform = transform;
```

#### 2. Использование viewBox для масштабирования
```javascript
// СТАЛО (правильно):
const width = originalWidth / zoom;
const height = originalHeight / zoom;
svg.setAttribute('viewBox', `${panX} ${panY} ${width} ${height}`);
```

### Преимущества viewBox:

1. **Настоящий векторный зум** - SVG перерисовывается с новым разрешением
2. **Идеальная четкость** на любом уровне приближения
3. **Плавная работа** без потери производительности
4. **Правильное масштабирование** всех элементов (линии, текст, графика)

## Технические детали

### Как работает viewBox

`viewBox` определяет область SVG, которая будет видна в контейнере:
```
viewBox="x y width height"
```

- `x, y` - начальная точка видимой области (для панорамирования)
- `width, height` - размер видимой области (для зума)

При зуме:
- **Увеличение (zoom > 1)**: width и height уменьшаются → видим меньшую область детальнее
- **Уменьшение (zoom < 1)**: width и height увеличиваются → видим большую область

### Преобразование координат

При работе с viewBox нужно преобразовывать координаты:

**Из пикселей экрана в координаты SVG:**
```javascript
const svgX = viewBox.x + (mouseX / containerWidth) * viewBox.width;
const svgY = viewBox.y + (mouseY / containerHeight) * viewBox.height;
```

**Панорамирование:**
```javascript
const dxSvg = (dxPixels / containerWidth) * viewBox.width;
const dySvg = (dyPixels / containerHeight) * viewBox.height;
```

### Улучшение качества рендеринга

Добавлены CSS свойства для максимальной четкости:
```javascript
svg.style.shapeRendering = 'geometricPrecision';
svg.style.textRendering = 'geometricPrecision';
```
