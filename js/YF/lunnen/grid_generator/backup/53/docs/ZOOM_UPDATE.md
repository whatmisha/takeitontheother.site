# ✨ Обновление: Zoom & Pan

## Что добавлено

Теперь в Pizza Boxer есть функциональность зума и панорамирования как в Figma! 🎨

### 🔍 Zoom (Масштабирование)
- Колесо мыши - зум с центром на курсоре
- Cmd/Ctrl + Plus/Minus - увеличение/уменьшение
- Cmd/Ctrl + 0 - подогнать под экран
- Cmd/Ctrl + 1 - сброс в 100%
- Двойной клик на индикатор зума - сброс в 100%

### 🖐️ Pan (Панорамирование)
- Пробел + перетаскивание - перемещение canvas
- Средняя кнопка мыши + перетаскивание - перемещение canvas

### 🎛️ UI
- Панель с кнопками зума внизу по центру
- Индикатор текущего уровня зума
- Кнопки: - / [%] / + / Fit / 1:1

## Как использовать

1. **Приближение**: Крутите колесо мыши вперед или нажмите Cmd/Ctrl + Plus
2. **Отдаление**: Крутите колесо мыши назад или нажмите Cmd/Ctrl + Minus
3. **Перемещение**: Зажмите пробел и перетащите canvas мышью
4. **Подогнать**: Нажмите кнопку с иконкой квадрата или Cmd/Ctrl + 0
5. **Сброс**: Нажмите кнопку "1:1" или дважды кликните на проценты

### Клавиатурные сокращения

| Действие | Сокращение |
|----------|-----------|
| Увеличение | Cmd/Ctrl + Plus или колесо вверх |
| Уменьшение | Cmd/Ctrl + Minus или колесо вниз |
| Панорамирование | Пробел + drag или средняя кнопка + drag |
| Fit to screen | Cmd/Ctrl + 0 |
| Сброс в 100% | Cmd/Ctrl + 1 или двойной клик |
