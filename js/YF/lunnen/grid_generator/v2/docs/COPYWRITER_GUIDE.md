# 📝 Инструкция для копирайтера

## Как редактировать тексты в экспортированном файле

### Шаг 1: Экспорт настроек

1. Откройте Pizza Boxer в браузере
2. Нажмите кнопку **Export Setup** внизу экрана
3. Скачается JSON с названием пресета и параметрами макета

### Шаг 2: Откройте файл в редакторе

Используйте любой текстовый редактор:
- **macOS:** TextEdit (откройте через Finder → Приложения → TextEdit)
- **Windows:** Notepad++ или обычный Блокнот
- **Для продвинутых:** VS Code, Sublime Text

### Шаг 3: Найдите секцию с текстами

Найдите раздел, который начинается с `"texts":`. Выглядит он примерно так:

```json
"texts": [
  {
    "id": "text_1",
    "content": "Здесь ваш текст",
    "style": "headline",
    "position": {
      "column": 1,
      "row": 2,
      "baseline": 5
    },
    "width": 6
  },
  {
    "id": "text_2",
    "content": "Еще один текст",
    "style": "text",
    "position": {
      "column": 1,
      "row": 5,
      "baseline": 15
    },
    "width": 12
  }
]
```

### Шаг 4: Редактируйте только поле "content"

**✅ Можно редактировать:**
- Текст внутри кавычек после `"content":`

```json
"content": "Замените это на нужный текст"
```

**❌ НЕ трогайте:**
- `"id"` — идентификатор блока
- `"style"` — стиль текста (headline, text, caption или lunnenDisplay)
- `"position"` — позиция на макете
- `"width"` — ширина блока
- Любые кавычки, запятые, скобки
- Любой код после секции `"graphics"` — это SVG-код, не текст

### Шаг 5: Сохраните файл

- **Важно:** Сохраните с тем же расширением `.json`
- **Кодировка:** UTF-8 (обычно по умолчанию)

### Шаг 6: Импортируйте обратно

1. Откройте Pizza Boxer в браузере
2. Нажмите кнопку **Import Setup**
3. Выберите отредактированный JSON-файл
4. Тексты на макете обновятся!

## 💡 Полезные советы

### Как понять, какой текст где находится

Каждый текстовый блок имеет идентификатор:
- `text_1` — первый текстовый блок
- `text_2` — второй текстовый блок
- и так далее

Если не помните порядок — откройте макет и посмотрите на панель **"Objects"** справа.

### Многострочный текст

Если нужен перенос строки внутри текста, используйте `\n`:

```json
"content": "Первая строка\nВторая строка\nТретья строка"
```

### Специальные символы

Некоторые символы нужно экранировать:
- Кавычки внутри текста: `\"` 
  ```json
  "content": "Текст с \"кавычками\" внутри"
  ```
- Обратный слэш: `\\`
  ```json
  "content": "Путь: C:\\Users\\Documents"
  ```

### Удаление текста

Чтобы удалить текст из блока, оставьте `content` пустым:

```json
"content": ""
```

## ⚠️ Что делать, если что-то сломалось

### Ошибка при импорте

Если после импорта появляется ошибка:
1. Проверьте, не удалили ли вы случайно запятую, кавычку или скобку
2. Убедитесь, что файл сохранен с расширением `.json`
3. Попробуйте открыть файл на [jsonlint.com](https://jsonlint.com/) — он покажет, где ошибка

### Частые ошибки

❌ **Забыли кавычки:**
```json
"content": Текст без кавычек  // НЕПРАВИЛЬНО
"content": "Текст с кавычками"  // ПРАВИЛЬНО
```

❌ **Лишняя или пропущенная запятая:**
```json
{
  "id": "text_1",
  "content": "Текст"  // Нет запятой — НЕПРАВИЛЬНО
  "style": "headline"
}

{
  "id": "text_1",
  "content": "Текст",  // Есть запятая — ПРАВИЛЬНО
  "style": "headline"
}
```
