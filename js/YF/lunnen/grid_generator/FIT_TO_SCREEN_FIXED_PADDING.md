# Fit to Screen с фиксированными отступами

## Изменение

Логика "Fit to Screen" теперь использует **фиксированные отступы в пикселях** вместо процентных, что обеспечивает предсказуемое и профессиональное размещение макета при загрузке.

## Параметры

### Отступы от краев окна:
- **Горизонтальные**: 360px слева и справа (итого 720px)
- **Вертикальные**: 80px сверху и снизу (итого 160px)

### Рабочая область:
- Canvas остается **fullscreen** (100% ширины и высоты окна)
- При зуме макет может выходить за пределы начальных отступов
- Пользователь может панорамировать и зумировать без ограничений

## Было vs Стало

### Было (процентные отступы):
```javascript
const paddingPercent = 0.05; // 5% от размера окна
const availableWidth = containerRect.width * (1 - paddingPercent * 2);
const availableHeight = containerRect.height * (1 - paddingPercent * 2);
```

**Проблема**: На разных размерах экрана отступы разные
- На 1920px экране: 96px отступы
- На 1280px экране: 64px отступы

### Стало (фиксированные отступы):
```javascript
const paddingHorizontal = 360; // 360px слева и справа
const paddingVertical = 80;    // 80px сверху и снизу
const availableWidth = Math.max(100, containerRect.width - paddingHorizontal * 2);
const availableHeight = Math.max(100, containerRect.height - paddingVertical * 2);
```

**Преимущество**: Одинаковые отступы на всех экранах
- На любом экране: 360px по бокам, 80px сверху/снизу

## Как работает

### При загрузке страницы:
1. Определяется размер окна браузера
2. Вычитаются фиксированные отступы: 720px по горизонтали, 160px по вертикали
3. Макет масштабируется так, чтобы поместиться в оставшуюся область
4. Макет центрируется в этой области

### При зуме:
- Пользователь может зумировать без ограничений
- Макет может выходить за пределы начальных отступов
- Вся область окна используется для панорамирования

### При нажатии "Fit to Screen":
- Макет возвращается к начальному масштабу с отступами
- Это всегда дает предсказуемый результат

```

│  ↓                                                      │

При зуме макет может занимать всё окно →
```

## Преимущества

✅ **Предсказуемость** - одинаковые отступы на всех экранах
✅ **Профессионально** - выверенные пропорции для комфортного просмотра
✅ **Оптимизировано** - 360px достаточно для панелей управления по бокам
✅ **Fullscreen работа** - при зуме используется вся область окна

## Адаптивность

На очень маленьких экранах есть защита от отрицательных значений:
```javascript
const availableWidth = Math.max(100, containerRect.width - paddingHorizontal * 2);
const availableHeight = Math.max(100, containerRect.height - paddingVertical * 2);
```

Минимальная доступная область: 100px × 100px

## Использование

### Автоматически:
- При загрузке страницы
- При загрузке пресета

### Вручную:
- Кнопка "Fit" в zoom controls
- Cmd/Ctrl + 0
- Кнопка с иконкой квадрата

## Рекомендации по размерам экрана

Оптимально для:
- **Desktop**: 1440px и шире (макет получает 720px+ для работы)
- **Laptop**: 1280px-1440px (макет получает 560px-720px)
- **Минимум**: 1024px (макет получает 304px)

Для мобильных устройств можно рассмотреть адаптивные отступы в будущем.
