# Быстрый старт — Пресеты

## Добавить новый пресет

### Шаг 1: Экспортируй
В Pizza Boxer → **Export Settings** → скачается JSON

### Шаг 2: Переименуй
```bash
mv grid-settings_*.json presets/"Название продукта.json"
```
💡 Имя файла = имя в дропдауне

### Шаг 3: Обнови список
```bash
python3 generate-presets-manifest.py
```

### Шаг 4: Обнови браузер
Cmd+R / Ctrl+R → готово!

---

## Использовать пресет

1. Открой Pizza Boxer
2. Вверху страницы серая кнопка = дропдаун с пресетами
3. Выбери нужный → всё загрузится автоматически

## Где что лежит

```
grid_generator/
├── presets/              ← твои пресеты здесь
│   ├── manifest.json     ← генерируется автоматически
│   └── *.json            ← файлы пресетов
└── generate-presets-manifest.py  ← запускай после добавления
```

---

## Частые вопросы

**Q: Пресет не появился в списке?**  
A: Запусти `python3 generate-presets-manifest.py`

**Q: Как переименовать пресет?**  
A: Переименуй файл → запусти скрипт → обнови браузер

**Q: Можно без скрипта?**  
A: Да, но долго. Редактируй `presets/manifest.json` вручную

**Q: Что если нет Python?**  
A: Используй `npm run presets` (нужен Node.js)
