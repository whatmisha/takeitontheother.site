How it Works?

This is a modular grid generator for Lunnen packaging design.

Default Layout

The default dimensions match the current Lunnen Outer 16 laptop packaging. The layout shows an unfolded box with five panels:

  • Front — Main panel
  • Left/Right — Side panels (vertical)
  • Top/Bottom — Flaps (horizontal)

Key Setting: Module

The Module setting (in millimeters) is the foundation of the entire grid system. It controls:

  • Baseline Grid — The finest grid division
  • Spacing — Gaps between Columns and Rows
  • Margins — Edge spacing
  • Row Height — Height of each row in modules

Perfect Fit Calculator

When Link Rows ⇄ Row Height is enabled, the interface suggests optimal combinations where rows fit perfectly into the layout height with an exact number of modules — no leftover space.

Export to Adobe Illustrator

Click Export SVG to download your grid. When opened in Adobe Illustrator, all dimensions will match the real millimeter measurements — ready for print production.
