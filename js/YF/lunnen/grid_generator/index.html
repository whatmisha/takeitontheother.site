🍕🥊 Pizza Boxer

Modular grid generator for packaging design based on the Lunnen system.

Canvas Dimensions

Front Width and Front Height define the working area dimensions in millimeters.

Thickness sets the depth of side panels.

Grid Module

The Module (in mm) is the base unit of the grid system. It controls:

  • Baseline Grid — Minimum grid step
  • Spacing — Gaps between columns and rows
  • Margins — Distance from edges
  • Row Height — Height of each row in modules

Rows and Columns

Columns — Vertical divisions with gutters between them.

Rows — Horizontal divisions based on the module and row height.

Baseline — Fine grid for aligning text to a vertical rhythm.

Link Modes

Control how parameters relate to each other:

  • Off — All parameters are independent
  • Rows × Height — Row count and row height are linked. Changing one recalculates the other to fit the canvas height
  • Module — Module is automatically calculated from canvas height, row count, and row height

Row Presets

When link mode is enabled, the interface displays combinations where rows fit the canvas height with exact module alignment.

Export SVG

Click Export SVG to download the grid. The file opens in Adobe Illustrator with accurate millimeter dimensions. Grid elements (columns, rows, baseline) are grouped separately and can be shown/hidden as needed.

Export Setup

Click Export Setup to save current configuration as a JSON file. The file includes all parameters, text blocks, and graphic elements.

Import Setup

Click Import Setup to load a previously saved JSON file. This restores the complete state including all objects and parameters.

Zoom and Pan

Navigate the canvas like in Figma (optimized for Apple Magic Mouse):

  • Scroll/Swipe — Pan the canvas (horizontal and vertical)
  • Cmd/Ctrl + Scroll — Zoom in/out (centered on cursor)
  • Space + drag — Alternative pan method
  • Middle mouse button + drag — Alternative pan method
  • Cmd/Ctrl + 0 — Fit to screen
  • Cmd/Ctrl + 1 — Reset zoom to 100%
  • Cmd/Ctrl + Plus — Zoom in
  • Cmd/Ctrl + Minus — Zoom out

Keyboard Shortcuts

  • Cmd/Ctrl + E — Export SVG
  • Arrow keys — Adjust slider values
  • Shift + Arrow keys — Adjust with larger step
