## 📦 Как использовать бэкапы

### Восстановление конкретной версии:
```bash
# Например, восстановить версию до рефакторинга
cp "backup/23 до рефакторинга/script.js" script.js
```

### Сравнение версий:
```bash
# Сравнить текущую версию с итерацией 1
diff script.js "backup/26 итерация 1 завершена (colorutils mathutils)/script.js"
```

### Просмотр конкретного бэкапа:
```bash
# Посмотреть содержимое бэкапа
ls -la "backup/42 итерация 9 завершена/"
```
