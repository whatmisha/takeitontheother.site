# Changelog

## [2.1.0] - 2025-11-16

### Добавлено ✨

#### Экспорт текста в кривых (Convert Text to Outlines)

Добавлена возможность экспорта SVG с автоматической конвертацией всего текста в векторные пути (paths). Это решает проблему отсутствующих шрифтов при открытии файла на других компьютерах или в типографии.

**Новые возможности:**
- ✅ Чекбокс "Convert text to outlines" под кнопкой Export SVG
- ✅ Автоматическая загрузка библиотеки opentype.js
- ✅ Поддержка всех используемых шрифтов (TT Commons Classic, Lunnen Display)
- ✅ Сохранение всех атрибутов текста (цвет, прозрачность, трансформации)
- ✅ Учет межбуквенного расстояния и кернинга
- ✅ Кэширование шрифтов для ускорения повторных экспортов

**Технические детали:**
- Новый модуль: `src/utils/TextToPath.js`
- Обновлен: `src/svg/SVGExporter.js` (добавлена поддержка async экспорта)
- Обновлен: `script.js` (интеграция TextToPath)
- Обновлен: `index.html` (новый UI элемент)
- Обновлен: `style.css` (стили для export-group)

**Документация:**
- Создан файл `FEATURE_TEXT_TO_OUTLINES.md` с подробным описанием
- Обновлен `README.md` с информацией о новой функции

### Использование

1. Откройте приложение в браузере
2. Создайте макет с текстовыми элементами
3. Перед экспортом установите чекбокс "Convert text to outlines"
4. Нажмите "Export SVG" (⌘E)
5. Дождитесь завершения конвертации (может занять несколько секунд при первом экспорте)
6. Скачайте готовый SVG файл с текстом в кривых

### Примечания

- Конвертация необратима в экспортированном файле
- Рекомендуется сохранить копию с редактируемым текстом через "Export Setup"
- Размер файла с кривыми будет больше, чем с текстом
- Требуется подключение к интернету для загрузки opentype.js (только при первом использовании)
