# Тестирование экспорта/импорта настроек

## Что было исправлено

### Проблема
- ❌ Файл сохранялся без текстов
- ❌ При импорте ошибка: `undefined is not an object (evaluating 'block.content.split')`

### Причина
Неправильный маппинг полей между внутренней структурой приложения и экспортным форматом:
- **Внутри приложения:** `content`, `styleRef`, `x`, `row`, `baselineOffset`
- **В экспорте был:** `text`, `styleType`, `columnIndex`, `rowIndex`, `baselineIndex`

### Решение
✅ Исправлен маппинг полей в `src/svg/SVGExporter.js`:

**Для текстовых блоков:**
- `content` → `content` (не `text`!)
- `styleRef` → `style`
- `x` → `position.column`
- `row` → `position.row`
- `baselineOffset` → `position.baseline`

**Для графических блоков:**
- `x` → `position.column` (не `columnIndex`!)
- `row` → `position.row` (не `rowIndex`!)
- `baselineOffset` → `position.baseline` (не `baselineIndex`!)

## Как протестировать

### Шаг 1: Откройте приложение
```bash
cd grid_generator
python3 -m http.server 8000
open http://localhost:8000
```

### Шаг 2: Проверьте текущее состояние
- Убедитесь, что на макете есть текстовые блоки
- Проверьте, что отображается графика (Icons, Claim)

### Шаг 3: Экспорт настроек
1. Нажмите **"Export Settings"**
2. Откройте скачанный JSON-файл
3. **Проверьте структуру:**
   - ✅ Есть `presetName` в начале
   - ✅ Секция `dimensions` с размерами
   - ✅ Секция `texts` с текстовыми блоками
   - ✅ В `texts` поле называется `content` (не `text`)
   - ✅ В `texts` поле `style` (не `styleType`)
   - ✅ SVG-код графики в конце

### Шаг 4: Редактирование текста
1. В секции `"texts"` найдите поле `"content"`
2. Измените текст, например:
```json
{
  "id": "headline",
  "content": "Новый заголовок для теста",
  "style": "headline",
  ...
}
```
3. Сохраните файл

### Шаг 5: Импорт настроек
1. Нажмите **"Import Settings"**
2. Выберите отредактированный JSON-файл
3. **Проверьте:**
   - ✅ Нет ошибок в консоли
   - ✅ Тексты обновились на макете
   - ✅ Графика отображается
   - ✅ Все настройки применились

## Если что-то не работает

### Ошибка: "undefined is not an object"
- Проверьте консоль браузера (F12 → Console)
- Проверьте, что файл JSON валиден (jsonlint.com)
- Убедитесь, что поле называется `content`, не `text`

### Тексты не сохраняются
- Откройте JSON-файл
- Проверьте секцию `"texts"`
- Должны быть объекты с полем `"content"`

### Графика не импортируется
- Проверьте секцию `"graphics"` в JSON
- Убедитесь, что есть SVG-код
