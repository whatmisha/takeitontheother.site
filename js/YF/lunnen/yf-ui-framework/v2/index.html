YF Tool — Help

This is a template for YF Tools applications. Customize the panels and canvas to build your tool.

Available Components

  • Sliders with value display, lock buttons, and unit toggles
  • HSB color picker with hex input
  • Toggle chips for layer visibility
  • Segmented controls for mode switching
  • Checkbox toggle switches
  • Dropdown selects
  • Textarea with character counter
  • Preset dropdown
  • Collapsible panels with drag support
  • Zoom & pan canvas

Keyboard Shortcuts

  • Arrow keys — Adjust slider values
  • Shift + Arrow — Adjust with larger step
  • ⌘/Ctrl + Scroll — Zoom canvas
  • Space + Drag — Pan canvas
  • ⌘/Ctrl + E — Export SVG
  • ⌘/Ctrl + Z — Undo
  • ⌘/Ctrl + Shift + Z — Redo
  • Escape — Close modal
