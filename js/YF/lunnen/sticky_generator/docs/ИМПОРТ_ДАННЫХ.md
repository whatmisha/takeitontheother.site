# Импорт данных из Google Таблиц

## Быстрый старт

### 1. Создайте таблицу в Google Sheets

Пример структуры для шаблона **Laptop Sticker**:

| A | B | C | D | E |
|---|---|---|---|---|
| Ноутбук Lunnen Ground 15.6"<br>Профессиональная работа<br>Игры в Full HD | LL5FAWG03 | Intel Core i5-1235U<br>16 GB RAM<br>512 GB SSD<br>Windows 11 Pro | 15.11.2024 | SN-2024-001 |

**Для многострочного текста в одной ячейке:**
- macOS: `Option + Enter`
- Windows: `Alt + Enter`

### 2. Опубликуйте таблицу

**Способ 1 (проще):**
1. `Файл` → `Опубликовать в веб`
2. Формат: `CSV` или `Веб-страница`
3. `Опубликовать` → Скопируйте ссылку

**Способ 2:**
1. Кнопка `Настройки доступа` (справа вверху)
2. `Доступ всем, у кого есть ссылка` → `Читатель`
3. Скопируйте ссылку

### 3. Загрузите данные

1. Откройте генератор стикеров
2. Панель **Data Import**
3. Вставьте ссылку на таблицу
4. Нажмите **Load Data**

### 4. Экспортируйте стикеры

- **Export Current Label** — один стикер (первая строка таблицы)
- **Generate All Labels** — все стикеры (по одному для каждой строки)

## Система плейсхолдеров

В шаблоне используйте обозначения:

- **Буква** (A-Z) = колонка таблицы
- **Трёхзначное число** (001-999) = строка ВНУТРИ ячейки

### Примеры

| Плейсхолдер | Значение |
|-------------|----------|
| `A001` | Колонка A, строка 1 |
| `B001` | Колонка B, строка 1 |
| `C002` | Колонка C, строка 2 |

### В шаблоне Laptop Sticker

```json
"A001"                          // Название продукта (строка 1 из колонки A)
"B001"                          // Серийный номер
"C001\nC002\nC003\nC004"       // Многострочное описание (строки 1-4 из колонки C)
"Серийный номер: E001"          // Текст с подстановкой
"Дата изготовления: D001"       // Текст с подстановкой
```

## Часто задаваемые вопросы

### ❓ Плейсхолдер не заменяется

**Проверьте:**
1. Формат: буква + трёхзначное число (`A001`, не `A1`)
2. Колонка существует в таблице
3. Строка существует в многострочной ячейке

### ❓ Ошибка загрузки данных

**Решение:**
1. Убедитесь, что таблица опубликована или доступна по ссылке
2. Проверьте права доступа (минимум "Читатель")
3. Попробуйте другой способ публикации

### ❓ Как посмотреть, что загрузилось?

Откройте консоль браузера (F12 → Console) — там будут логи:
- ✅ Успешная замена плейсхолдеров
- ⚠️ Предупреждения о проблемах
- 🔄 Процесс загрузки
