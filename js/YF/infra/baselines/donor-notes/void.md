# Void donor

Void не копируется в upgrade. Активный root без `wip/` используется для анализа общих решений.

Можно перенести как framework-концепции:

- deterministic random state;
- per-preset history;
- shared temporary preset;
- short/full share URLs;
- unsaved guard;
- export parity;
- optional mobile bootstrap.

Не переносить:

- glyph/alphabet/editor domain code;
- ModuleDrawer и EndpointDetector;
- Void analytics;
- external About/SEO deployment metadata;
- `wip/` snapshots.
