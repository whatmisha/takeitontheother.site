# Full Canvas starter

This is the canonical full-feature Canvas reference application for UI Garage.
It imports only `../../src/index.js` and contains no framework implementation.

Included workflows:

- deterministic DPR-aware Canvas rendering with zoom, pan and fit;
- declarative sliders, toggles, unified color controls and collapsible panels;
- undo/redo, bundled and user presets, persistence and share URLs;
- image picker/dropzone with a session-only decoded asset;
- validated JSON import with rollback plus JSON export;
- pixel-safe 1×/2× PNG export and an explicit SVG export hook;
- status, error/dialog, keyboard help and canonical shortcuts;
- responsive mobile coordination and symmetric destroy/re-init.

Serve the UI Garage directory and open `starters/canvas-full/`. Do not open the
HTML through `file://`.
