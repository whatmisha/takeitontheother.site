# UIQ 3 — источники Dither, кнопки панели и границы холста

2026-09-21. Рабочие изменения поверх `b614ffc`; не commit и не публикация. Все изменения этой задачи внутри `upgrade/`. Параллельные изменения Pulsar и других задач не откатывались.

## Исправлено

- Reset сливался с панелью из-за локального `#transformPanel .btn-secondary`: фон совпадал с фоном панели. Локальные правила обычных кнопок удалены. Общий opt-in `.panel-action`: высота 36px, текст 16px / 500, чёрная поверхность, #d2d2d2 текст; hover инвертирует цвета, focus-visible 2px, disabled #111 / #666. Отдельная обводка в покое не нужна.
- Image / Layout, их удаления и статусы перемещены в Texture → Sources. Общие групповые заголовки и file-intake--panel; ID и обработчики сохранены. Reset находится в группе Transform. В dock больше нет операций над источниками.
- ⌘O/⌘I описаны прежней metadata; новый явный `data-file-shortcut-persistent` сохраняет команды и строки справки при collapse. Скрытое через hidden или disabled действие не запускается. Остальные скрытые команды не становятся активными автоматически.
- Preview Dither ограничивался `max-height:70vh`, а overlay оставался в исходном размере. Теперь ResizeObserver синхронизирует CSS-размеры, включая overflow padding; mousedown/mousemove переводятся в координаты буфера. Буферы, алгоритмы dithering и размеры PNG не меняются.
- `.ui-artboard`: отдельная экранная граница выходного листа 1px / #333. В Dither подключена к основному canvas, не к overlay. CSS outline не записывается в растровый экспорт и не занимает место в layout.
- Component Lab использует те же кнопки и содержит normal/disabled примеры. Аудитор uiq-4 проверяет кнопки панели, расположение источников, масштаб и центр overlay, границу листа, команды импорта в справке. Семантика остальных рамок отмечается как требующая проверки, не как автоматический успех.

Пример исправленной геометрии в 1280 × 720: canvas buffer 579 × 600 → CSS 486.36 × 503.99; overlay buffer 979 × 1000 → CSS 822.35 × 839.98. Больший overlay — намеренное поле для трансформации за пределами листа; его CSS-масштаб и центр совпадают с основным canvas.

Временные вкладки закрыты, collapse восстановлен, пользовательская вкладка аудита не закрывалась. Файлы через браузер не экспортировались; PNG artifact/lifecycle проверены unit-тестами. Drag-and-drop, отмена chooser, повреждённый файл и полный набор scale/alpha комбинаций в браузере в этой итерации не проверялись.

## Автоматические проверки

- Dither + UnifiedUi + public API: 36/36, включая 4 новых Dither-теста и новый collapse/shortcut-тест.
- `npm --prefix upgrade run test:tier1`: успешно (framework, Sparky, Pizza, Wordplayer, Keyboarder, Sticky).
- Wander: 12/12.
- `check:component-lab`, `check:boundaries`, `check:storage`, `check:toggles`: успешно. `check:ui-contract` прошёл первый прогон; при заключительном повторе остановился на изменившейся версии UnifiedUi в entrypoint Pulsar (параллельная правка). Версия остальных приложений не подгонялась под неё.
- `check:actions`, `check:file-intake`, `check:ranges` останавливаются на параллельной переработке Pulsar: 4 кнопки вместо 3, появился decodeInput, 7 диапазонов вместо 8. Эти ожидания не подгонялись в данной задаче. Изменён только Dither-состав dock (минус четыре source-кнопки).
- В журнале аудитора при перезагрузке iframe наблюдались две ошибки MutationObserver «parameter 1 is not of type Node». Сам замер завершился, новые проверки совпали; это не считается чистой консольной приёмкой. В общих lifecycle-модулях уже есть обработка гонки документа, но источник оставшихся ошибок и повторная проверка требуют отдельного разбора. Не менять параллельные правки вслепую.

## Рамки: что одинаково только внешне

Это source-аудит семантики, не завершённая визуальная приёмка всех восьми инструментов.

| Инструмент | Текущее назначение / отличие | Безопасное следующее действие |
| --- | --- | --- |
| Dither | Выходной лист + независимая рамка трансформации изображения | Исправлено: общий экранный edge и согласованный overlay; ручки оставлены |
| Wordplayer | Логический лист рисуется внутри canvas с pan/zoom; отдельного edge в drawScene нет | Экранный слой по логическим bounds; не CSS-рамка всего viewport и не линия внутри экспортируемого canvas |
| Keyboarder | Фоновый rect логического листа без stroke внутри SVG; есть другие контуры клавиш/выделения | Preview-only граница листа с явным исключением из SVG/PNG/PDF |
| Sticky Fingers | Фоновый rect этикетки без stroke; сетка и выделения имеют собственные контуры | Preview-only граница этикетки; сохранить размеры и печатную геометрию |
| Pizza Boxer | Контуры граней упаковки в CanvasRendererController; этот renderer используется экспортом | Не заменять stroke как «UI-обводку»: сначала отделить печатные границы от оформления предпросмотра |
| Wander Bender | area-boundary обозначает область генерации, исключается из экспорта | Сохранить семантику и exclusion; если унифицировать цвет/толщину, только после проверки zoom |
| Sparky | Полноэкранная сцена, отдельные направляющие/геометрия, важна mobile-версия | Не добавлять рамку браузерного viewport; сначала определить, нужен ли вообще видимый лист |
| Pulsar | Прозрачная генерация, частные лучи/оси; параллельная переработка | Не менять текущую ветку работ; описать bounds/экспорт после стабилизации |

Правило для следующей задачи: одна роль **preview artboard edge**, но разные технические адаптеры Canvas/SVG. Цвет #333, толщина 1 CSS px независимо от zoom; не экспортировать и не перехватывать мышь. Проверить светлый/тёмный фон, fit, масштаб, pan, resize и экспортные артефакты. Не выдавать просто добавленную `.ui-artboard` на viewport за выполнение этого требования.
