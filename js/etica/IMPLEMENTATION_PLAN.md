# Etica: актуальный план

## 1. Что такое Etica сейчас

Etica — локальное браузерное приложение на plain HTML/CSS/JavaScript + Canvas 2D. Главная модель данных — не плоская картинка, а список `strokes`, которые перерисовываются brush engine. Это важно для undo/redo, изменения параметров, выделения, генераторов, прозрачного экспорта и будущей анимации.

Текущие режимы:

- `Etica Pinta` — ручное рисование точечной и ink-кистью, eraser, select/move, undo/redo.
- `Foto` — старый фото-генератор из масс/контуров; вероятно будет удален позже.
- `Nuevo` — будущий основной режим фото -> линейная точечная иллюстрация.
- `Flor` — процедурный генератор растений.
- `Doodle Flor` — простой параметрический генератор дудл-цветов; ориентир для новых генераторов.

Подтвержденная визуальная норма:

- фон по умолчанию: `#BBBBBB`;
- кисть по умолчанию: `#000000`;
- генераторы используют текущий brush color;
- эффекты опциональны и нужны реже, чем обычная статичная картинка.

## 2. Архитектура

Ключевые файлы:

- `index.html` — разметка приложения и панелей.
- `css/ui-base.css`, `css/styles.css` — локальная UI-система и layout.
- `js/main.js` — инициализация app/controller/ui.
- `js/canvas/CanvasController.js` — документ, strokes, render, selection, undo/redo, export.
- `js/canvas/Exporter.js` — PNG/GIF/JSON download helpers.
- `js/brushes/BrushEngine.js` — raster stamp rendering, eraser, wind/boil effects.
- `js/brushes/stamps.js` — процедурные noisy stamps.
- `js/input/PointerTracker.js` — Pointer Events для mouse/touch/stylus.
- `js/ui/Toolbar.js` — режимы, панели, хоткеи, генераторы.
- `js/generators/StrokeFactory.js` — создание валидных generated strokes.
- `js/generators/*Generator.js` — Foto/Nuevo/Flor/Doodle Flor.

Генераторы продолжают работать как сейчас: live-регенерация заменяет текущую generated group в документе. Отдельные `Preview`/`Apply` пока не нужны.

Управление generated groups пользователю пока не показываем. Генератор может заменять свою последнюю группу, но ручной интерфейс остается простым.

## 3. Ближайший продуктовый фокус

Главный ближайший фокус — качество `Nuevo`.

Цель `Nuevo`: из фото получать не пятнистый фильтр, а простую точечную иллюстрацию, где форма читается через линии. Это особенно важно для портретов, но режим должен работать и для предметов, растений, одежды, интерьеров и малоконтрастных фото.

Референс: портрет собран из черных точек, которые выстраиваются в линии формы: контур головы, волосы, брови, глаза, нос, рот, подбородок, плечи. Пятна допустимы только там, где они выглядят как плотность линии, а не как залитые тени.

Текущая проблема `Nuevo`:

- алгоритм выбирает отдельные сильные пиксели-кандидаты;
- fill внутри темных масс быстро превращает изображение в пятна;
- слабоконтрастные фото дают мало полезных линий;
- точки не всегда распределяются вдоль связанной формы.

План улучшения `Nuevo`:

1. Усилить локальные линии на слабоконтрастных фото:
   - локальное среднее и локальная дисперсия;
   - adaptive contrast map;
   - edge map по яркости + цветовым каналам.
2. Распределять точки вдоль связанных line components:
   - строить тонкую карту кандидатов;
   - группировать соседние edge-пиксели;
   - давать каждой линии квоту точек;
   - выбирать точки вдоль компонента с учетом spacing.
3. Сильно ограничить mass fill:
   - fill должен быть вторичным;
   - по умолчанию меньше крупных точек;
   - темные области лучше описывать контурами и внутренними линиями.
4. Улучшить portrait behavior без превращения режима в портретный-only:
   - позже можно добавить optional face landmarks для глаз/носа/рта;
   - при отсутствии лица алгоритм должен оставаться общим line extractor.

## 4. Внешние инструменты для будущего Nuevo

Сейчас базовый путь — нативный Canvas без зависимостей. Но есть три реалистичных направления:

- OpenCV.js: Canny, adaptive thresholding, contours, HoughLinesP. Хорошо для классической CV-обработки, но может добавить вес и потребует аккуратной загрузки wasm.
- MediaPipe Face Landmarker: полезен как optional portrait-assist слой для подсказок по глазам, носу, губам и овалу лица. Не должен быть обязательным для всех изображений.
- ONNX Runtime Web + edge model: путь для HED/DexiNed-подобного нейросетевого edge detector в браузере. Потенциально лучший для “умных” границ формы, но самый тяжелый и потребует отдельного исследования модели, веса, latency и fallback.

Официальные отправные точки:

- OpenCV.js Canny: https://docs.opencv.org/4.x/d7/de1/tutorial_js_canny.html
- OpenCV.js adaptive thresholding: https://docs.opencv.org/4.x/d7/dd0/tutorial_js_thresholding.html
- OpenCV.js contours: https://docs.opencv.org/4.x/d0/d43/tutorial_js_table_of_contents_contours.html
- MediaPipe Face Landmarker Web: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js
- ONNX Runtime Web: https://onnxruntime.ai/docs/get-started/with-javascript/web.html
- HED paper: https://arxiv.org/abs/1504.06375

## 5. Doodle Flor и новые параметрические генераторы

`Doodle Flor` — правильный ориентир для следующих генераторов:

- генератор должен создавать strokes, а не bitmap;
- результат должен выглядеть нарисованным точками, не SVG-стерильно;
- параметры должны менять композицию заметно и предсказуемо;
- seed должен давать повторяемый результат;
- live-регенерация остается текущей моделью.

После первого улучшения `Nuevo` следующий фокус — доработка `Doodle Flor` и новые генераторы такого же типа.

## 6. Selection на будущее

Сейчас линия выбирается кликом/hit-test. Проблема: линии, перекрытые другими линиями, нельзя удобно выбрать.

Предлагаемое решение, пока без реализации:

- `Alt`/`Option` + click открывает маленький cycle-picker около курсора;
- picker показывает несколько кандидатов под точкой, отсортированных сверху вниз и по расстоянию;
- повторный `Alt`/`Option` + click в той же точке циклически переключает кандидата;
- подсветка показывает выбранный stroke или generated group;
- `Tab`/`Shift+Tab` в режиме Select может переключать соседние candidates в последнем hit-test наборе.

Это сохраняет простой обычный клик, но дает точный доступ к перекрытым линиям.

## 7. Экспорт и developer tools

Пользовательский экспорт:

- PNG с фоном;
- прозрачный PNG;
- прозрачный GIF с boil.

Developer-only экспорт:

- JSON document export нужен нам для отладки и обмена состоянием;
- кнопка JSON скрыта по умолчанию;
- клавиша `J` показывает/скрывает кнопку экспорта JSON;
- импорт JSON пока не нужен, но формат должен быть пригоден для будущего импорта.

## 8. Мобильный режим

Мобильная версия — быстрый режим:

- рисование;
- загрузка фото-подложки;
- быстрый размер кисти;
- undo/redo;
- preview animation;
- export/copy transparent.

Полноценный редактор на мобильном пока не цель.

## 9. Что не делаем сейчас

- prompt-to-image;
- серверную обработку фото;
- обязательные внешние ML-модели;
- управление generated groups в пользовательском UI;
- полноценную галерею;
- импорт JSON;
- превращение `Nuevo` в портретный-only режим.
